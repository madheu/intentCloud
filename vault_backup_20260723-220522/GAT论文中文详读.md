## 一、开门：用「老侦探的信息源分级」理解 GAT

想象一位老刑警在破案。他召集所有目击者问话，但不急于整合证词——他先做一件事：**判断每个目击者的可信度**。那个站在远处、眼神犹疑的人，证词权重给低一点；那个近距离看清全过程、说话笃定的人，权重给高一点。然后才把加权后的证词综合起来推理案情。

这个"先评估可信度，再加权整合"的步骤，就是 GAT 的核心思想。

对比之下，前面的方法：
- **GCN** 的做法是：把所有目击者的证词**直接平均**，不管谁看得清谁看不清（固定的重整化邻接矩阵 ˆA）
- **GraphSAGE** 的做法是：随机抽几个目击者问话，然后**再平均一遍**（均匀采样 + mean/pooling）

GAT 说：等等，**不是所有邻居都同等重要**。

> 跟海波围合的关系：海波当前的围合计数也是**所有参与围合的邻居等权相加**。GAT 的「邻居重要性差异化」思路值得借鉴——但 GAT 靠反向传播学这个重要性，海波需要用赫布式局部信号来估计。

## 二、核心要解决的问题

### 2.1 GCN 和 GraphSAGE 的共同盲点：等权重假设

| 方法 | 邻居权重策略 | 能否区分谁更重要 |
|------|-------------|:--------------:|
| GCN | `Ã = ˜D^(-1/2) ˜A ˜D^(-1/2)`（固定的归一化权重） | ❌ 完全不能 |
| GraphSAGE | 均匀采样 + mean/pooling/LSTM 聚合 | ❌ 聚合后统一处理 |
| **GAT（本文）** | **每个邻居动态计算注意力权重 α_ij** | ✅ **可以** |

这个"等权重假设"在实践中是很大的限制：

- 在引文网络中，一篇文章的被引可能来自截然不同的领域。有些引用是"相关工作"（高相关），有些只是"顺带提了一句"（低相关）。GCN 把两者一视同仁。
- 在蛋白质交互网络中，一个蛋白质可能跟很多其他蛋白质有交互，但只有部分交互携带关键功能信号。
- 在海波的语义图中，"苹果"概念节点可能同时连接到"水果"义原和"公司"义原。围合时，需要的上下文不同，对这两个邻居的权重应该动态调整——但当前做法是等权相加。

### 2.2 GAT 的三个目标

| 目标 | 描述 |
|------|------|
| **自适应邻居权重** | 让每个节点动态学习哪些邻居更重要 |
| **兼容不同度的节点** | 节点度可以任意（从1到上万），不需要固定大小采样 |
| **归纳式能力** | 注意力机制是「边共享的」→ 未见节点也能计算 |

> **核心贡献：第一个在图上引入自注意力（self-attention）的神经网络架构，用共享的注意力机制取代固定的卷积核或均匀采样。**

## 三、核心方法

### 3.1 图上自注意力层（Graph Attentional Layer）

GAT 的单层设计分为四步：

#### 步骤一：线性变换（共享参数）

每个节点特征通过一个共享的权重矩阵 W 做线性变换：

```
h_i → W h_i     (W ∈ R^(F' × F))
```

这一步和 GCN 相同——先用一个可训练的线性层提升表达能力。

#### 步骤二：计算注意力系数 e_ij

对每一对相邻节点 (i, j)，计算 j 对 i 的重要性：

```
e_ij = a(W h_i, W h_j)
```

其中 a 是一个**共享的单层前馈网络**（参数为向量 a ∈ R^(2F')），输出一个标量：

```
e_ij = LeakyReLU( a^T · [W h_i ∥ W h_j] )
```

这里的 LeakyReLU 负斜率 α=0.2，∥ 是拼接操作。

**关键区别**：这里没有显式的 query/key/value 区分。相比于 Transformer 的 Q·K^T 点积注意力，GAT 的注意力是一种**拼接+单层网络**的形式（additive attention / Bahdanau attention）。

#### 步骤三：Masked Attention + Softmax 归一化

只计算**一阶邻居**（含自环）的 e_ij——这就是 masked attention（遮罩注意力），把图结构通过邻接关系注入：

```
α_ij = softmax_j(e_ij) = exp(e_ij) / Σ_{k∈N_i} exp(e_ik)
```

归一化后的 α_ij 满足 Σ_j α_ij = 1，可以直接作为加权系数使用。

#### 步骤四：加权聚合输出

```
h'_i = σ( Σ_{j∈N_i} α_ij · W h_j )
```

每个节点的输出是其邻居特征（经 W 变换后）的**加权和**，权重由注意力系数 α_ij 决定。

### 3.2 多头注意力（Multi-Head Attention）

为了稳定自注意力的训练过程，GAT 借鉴了 Transformer 的多头注意力：

```
h'_i = ∥_{k=1}^{K} σ( Σ_{j∈N_i} α^k_ij · W^k h_j )
```

- K 个独立的注意力机制并行计算
- 中间层：K 个头的输出**拼接**（concatenation），维度变为 K·F'
- 最后一层（预测层）：K 个头的输出**平均**，再接 softmax

**默认配置**：K=8，F'=8（每头）→ 中间层每节点 64 维

### 3.3 与 Transformer 注意力的对比

| 维度 | Transformer | GAT |
|------|-----------|-----|
| 注意力范围 | 全局（序列所有位置） | 局部（一阶邻居 + 自环） |
| 注意力计算 | 点积 Q·K^T / √d | 拼接 + 单层网络 (Bahdanau) |
| 多头机制 | 拼接后线性投影 | 拼接（中间层）/平均（输出层） |
| 图结构注入 | 位置编码 | Masked attention |
| 掩码方式 | Padding mask | 邻接矩阵 mask |

### 3.4 计算复杂度

单个注意力头的时间复杂度：**O(|V|·F·F' + |E|·F')**

- |V|·F·F': 所有节点的线性变换
- |E|·F': 所有边上的注意力计算

与 GCN 的复杂度 O(|V|·F·F' + |E|·F') 完全同阶。多头注意力将参数和存储增大 K 倍，但各头可并行。

## 四、关键结果

### 表1：直推式节点分类准确率（%）

| 方法 | Cora | Citeseer | Pubmed |
|------|:----:|:--------:|:------:|
| MLP | 55.1 | 46.5 | 71.4 |
| GCN | 81.5 | 70.3 | 79.0 |
| MoNet | 81.7 ± 0.5 | — | 78.8 ± 0.3 |
| **GAT（本文）** | **83.0 ± 0.7** | **72.5 ± 0.7** | **79.0 ± 0.3** |

- Cora 提升了 1.5%（81.5 → 83.0），Citeseer 提升了 1.6%（70.3 → 72.5）
- Pubmed 持平（79.0），原因是 Pubmed 只有 60 个训练样本，注意力的优势发挥不出来

### 表2：归纳式（PPI 数据集）F1 分数

| 方法 | PPI (micro-F1) |
|------|:--------------:|
| GraphSAGE-GCN | 0.500 |
| GraphSAGE-mean | 0.598 |
| GraphSAGE-LSTM | 0.612 |
| GraphSAGE-pool | 0.600 |
| GraphSAGE*（作者复现最佳） | 0.768 |
| **Const-GAT**（等权重基线） | **0.934 ± 0.006** |
| **GAT（本文）** | **0.973 ± 0.002** |

**关键发现**：

1. **GAT 在 PPI 上碾压 GraphSAGE**（0.973 vs 0.612），提升巨大——主要原因不是注意力本身，而是**全邻域聚合 + 注意力**的结合
2. Const-GAT（等权重注意力，≈GCN 的归纳式版本）已到 0.934，说明**不采样、用全部邻居**本身就远超 GraphSAGE 的采样策略
3. 注意力在 Const-GAT 基础上又加了 3.9%（0.934 → 0.973），证明了差异化加权的实际收益

> **对海波的启发**：全邻域聚合 > 采样聚合。海波当前就是全邻域围合，这点是对的。但「全邻域 + 等权重」还不是最优——GAT 证明差异化权重有价值。

## 五、与海波语义图的深层联系 ⭐

### 5.1 核心洞察

```
GAT 的核心改进：         从「所有邻居等权重」→「动态学习每个邻居的重要性」
                              ↓
海波当前的问题：         围合计数对所有邻居等权相加（类似 GCN 的 Ã 或 GraphSAGE 的 mean）
                              ↓
GAT 的思路启发海波：    围合时也可以差异化权重，只是权重来源不能是反向传播
```

### 5.2 结构性对齐

| GAT 元素 | 海波对应 | 对齐程度 |
|---------|---------|:--------:|
| 自注意力（masked attention） | 围合（enclosure）：关注邻居对当前概念的贡献 | ✅ 问题同构 |
| 注意力系数 α_ij | 概念 j 对概念 i 的「当前上下文重要性」 | ✅ 目标同构 |
| 多头注意力（K 个头） | 多种围合视角（不同关系类型、不同维度） | ✅ 形式同构 |
| 共享注意力机制 a | 共享的围合计算规则（如共现计数+激活强度） | ⚠️ 机制不同 |
| 加权邻居聚合 Σ α_ij · W h_j | 加权围合得分 Σ w_ij · activation_j | ✅ 完全同构 |
| 最后一层多头平均 | 多视角围合得分的平均融合 | ✅ 直接可用 |

### 5.3 关键差异：学习机制

| 维度 | GAT | 海波语义图 |
|------|-----|-----------|
| **注意力权重来源** | 反向传播训练（a 和 W 都可学） | 必须局部计算（Hebbian / 激活模式） |
| **参数是否可训练** | ✅ 是（端到端梯度下降） | ❌ 否（无反向传播） |
| **是否需标签** | ✅ 需要交叉熵损失 | ❌ 不需要 |
| **权重的可解释性** | α_ij 可解释（但参数 a, W 不可解释） | w_ij 是可解释的语义关联强度 |
| **注意力范围** | 固定一阶邻居（masked by adjacency） | 固定一阶邻居（围合范围就是邻域） |
| **动态性** | 权重在训练后固定，推理时不变 | 每次交互激活不同子图 |

### 5.4 可以借用的东西 ✅

| 优先级 | 借用内容 | 对应海波改动 |
|:-----:|---------|------------|
| **P1** | **注意力系数 α_ij 的设计思路** — 不同邻居对当前概念的贡献应当不同 | 围合得分改为加权求和，权重根据概念激活模式计算 |
| **P1** | **多头注意力（multi-head）** — 多个独立的围合视角 | 将围合从「单视角计数」扩展到「K 头围合」 |
| **P1** | **最后一层多头平均** — 多视图融合策略 | K 个围合头的输出平均作为最终消歧得分 |
| **P2** | **Masked attention 的局部性** — 只关注一阶邻居 | 海波当前已经这么做了，但可以更有意识地控制围合范围 |
| **P3** | **共享参数（边共享机制）** — 同一计算规则应用于所有边 | 海波的赫布权重更新本身就是共享规则 |

### 5.5 绝对不能借用的东西 ❌

| 不可借用 | 原因 |
|---------|------|
| 可训练的注意力参数 a 和 W | 违反「无反向传播」的核心方法论。注意力权重必须来自局部计算 |
| 反向传播训练整个网络 | 这是铁律。海波的核心创新就是赫布式局部学习代替全局梯度下降 |
| 交叉熵损失 + SGD 优化 | 海波无监督、无标签，没有任何损失信号可用 |
| 监督/半监督训练范式 | GAT 的论文实验全部是监督或半监督的，海波需要完全无监督 |
| Dropout 在注意力系数上 | GAT 在 α_ij 上做 dropout（随机暴露子邻域），这是训练技巧，海波无训练阶段 |
| Glorot 初始化 + 早停策略 | 这些都是在有监督训练语境下的优化策略 |

### 5.6 从 GCN → GraphSAGE → GAT → 海波的演进脉络

```
GCN（2017, Kipf）:       等权重 ˆA    × 直推式    × 全图
                           ↓
GraphSAGE（2017）:        均匀采样    ✓ 归纳式   ✓ 局部
                           ↓              × 仍等权重
GAT（2018, Veličković）:  自适应权重   ✓ 归纳式   ✓ 局部
                           ↓              × 需反向传播
海波语义图（本项目）:     自适应围合   ✓ 动态图   ✓ 赫布式
                         （围合权重来自激活模式，非训练）
```

## 六、具体的实验想法

### 实验：多头围合——多概念子空间围合能否提升消歧？

**问题**：海波当前的围合是单视角的。能否借鉴 GAT 的多头注意力，从 K 个不同的概念子空间对邻居做围合计数，然后将 K 个头的得分平均，得到更鲁棒的消歧结果？

**设计**：

```python
# 基线（当前做法）：单头围合
score_i = Σ_j w_ij · activation_j     # 单视角加权求和

# 实验组（多头围合）：K 头并行
head_1_score_i = Σ_j w^1_ij · activation_j    # 头1：共现频率视角
head_2_score_i = Σ_j w^2_ij · activation_j    # 头2：义原语义相似度视角
head_3_score_i = Σ_j w^3_ij · activation_j    # 头3：上下文激活强度视角
head_4_score_i = Σ_j w^4_ij · activation_j    # 头4：转移概率（随机游走）视角

# 融合：最后一层平均
final_score_i = mean(head_1_score_i, ..., head_K_score_i)
```

**关键约束**：每个头的权重 w^k_ij 必须来自**局部可计算的信号**（共现频率、激活强度等），绝不能引入反向传播。

**假设**：
- 不同头捕捉不同语义关系类型（如：头 1 侧重「经常一起出现的概念」，头 2 侧重「语义相近的概念」）
- 多头平均比单头更稳定，因为不同头在不同上下文下的优势互补

**评价指标**：
- 消歧准确率 vs 人工标注
- 各头的注意力分布可解释性（哪个头在什么场景下主导决策）
- 多头 vs 单头的方差比较

**关联实验**：可复用 [[P0 Series Experiments]] 中的 P0-B（HowNet sememe + LLM context）数据集。

## 七、批判性评价

### 优点

1. **精准地解决了 GCN/GraphSAGE 的关键局限** — 「所有邻居等权重」这个简化假设从 GCN 第一天起就是痛点，GAT 给出了最直接的解决方案
2. **设计干净、可复现** — 整篇论文的核心创新就是一行公式（Eq.3），但这一行带来的提升是实质性的。代码开源（~200 行核心实现）
3. **全邻域聚合的威力** — Const-GAT 在 PPI 上的 0.934 证明了不采样（用全部邻居）本身就比采样好，这对 GraphSAGE 的「必须采样」教条是一个修正
4. **多头注意力是对「单一注意力不可靠」的优雅解决方案** — 用多个独立头的平均来稳定学习，这个设计思想在海波语境中可以直接复用
5. **归纳式和直推式兼顾** — 共享注意力机制本质上与具体图结构解耦，这是从谱方法到空间方法的真正跨越

### 弱点

1. **仍然是全监督/半监督范式** — GAT 的注意力系数 α_ij 是通过反向传播学出来的。论文题目叫"Graph Attention Networks"，但注意力本质上是训练产物，不是先验知识。对海波这种无监督场景，GAT 的注意力机制本身不能被直接采用
2. **Cora/Citeseer 提升有限（~1.5%）** — 注意力机制在小图上提升并不显著。Ppubmed 甚至完全持平。注意力在大图（PPI，56944 节点）上才真正发挥优势
3. **注意力系数 α_ij 的可解释性被夸大了** — 论文做了 t-SNE 可视化，但承认「需要领域知识来真正解释这些系数」。在图注意力中，α_ij 本质上是一个高维非线性函数的输出，它≠语义上的"重要性"（这是注意力可解释性的普遍问题）
4. **计算复杂度对大图不友好** — O(|E|) 意味着边数线性增长。对于边数十亿的社交网络，计算所有边的注意力系数是巨大的开销
5. **K=8 是经验值，无理论指导** — 为什么 8 个头最好？不是 6 不是 12？缺乏理论解释
6. **空间局部性限制** — 仍然是一阶邻居的线性组合+多层堆叠获得多跳，跟 GCN 在感受野上无区别

## 九、相关文献路线

```
GCN (Kipf & Welling, 2017, ICLR)
  等权重 × 直推式
   ↓ (归纳式 + 采样)
GraphSAGE (Hamilton et al., 2017, NIPS)
  等权重 ✓ 归纳式
   ↓ (注意力 + 差异化权重)
GAT (Veličković et al., 2018, ICLR) ← 这篇论文
  自适应权重 ✓ 归纳式
   ↓ (图结构表达能力)
GIN (Xu et al., 2019, ICLR)
  图同构表达能力上限
   ↓ (可扩展性)
Cluster-GCN / GraphSAINT / GaAN
  大规模图上的注意力/采样优化
```

| 相关工作 | 对海波的核心启发 | 核心冲突 |

| **MoNet** | 统一的空间图卷积框架 | 不同的伪坐标函数选择 |

## 十、一句话总结

> **GAT 用自注意力机制实现了「邻居重要性差异化」，解决了 GCN/GraphSAGE 的等权重假设问题——但它的注意力权重是通过反向传播学出来的，海波不能直接复制；对海波最有价值的是「多头围合」的设计思路和多头融合策略，而非 GAT 的具体参数学习范式。**

### A1 问题映射

| GAT 的问题 | → | 海波语义图的对应问题 |
|-----------|:-:|-------------------|
| 图上节点分类（半监督/监督） | → | Semantics Graph 语义消歧（无监督） |
| 自适应邻居重要性加权 | → | 围合计数中的差异化概念贡献度 |
| 所有邻居等权重 → 差异化权重 | → | 当前等权围合 → 多视角加权围合 |
| Masked attention（只关注一阶邻居） | → | 围合范围（目标概念的 1-hop 邻域） |
| 多头注意力 + 平均融合 | → | 多概念视角的围合得分融合 |
| 归纳式推理（未见图直接泛化） | → | 动态图的自然需求（新概念随时加入） |

**判定**：问题结构高度同构 ✅ — GAT 的「差异化邻居权重」和「多头融合」两个设计思路可以直接映射到海波的围合优化。

---

### A2 算法对齐

| 步骤 | GAT 做法 | 海波当前做法 |
|------|---------|------------|
| 邻居选择 | Masked attention：一阶邻居（含自环） | 1-hop 围合邻域（所有邻居参与） |
| 重要性计算 | `α_ij = softmax(LeakyReLU(a^T[Wh_i∥Wh_j]))` | 无 — 所有邻居等权重 `1/deg(i)` |
| 线性变换 | `W h_j` 共享参数 | 无 — 直接使用节点激活值（无参数变换） |
| 聚合方式 | `Σ α_ij · (W h_j)` 加权求和 | `Σ 1/deg(i) · activation_j` 等权求和 |
| 自身拼接 | 通过自环隐含包含自身（i ∈ N_i） | 无显式自身拼接 |
| 多视角 | 多头注意力 `K=8`，拼接后平均 | 单头（单一围合视角） |
| 融合策略 | 中间层拼接，输出层平均 | N/A |
| 参数更新 | SGD + 反向传播（端到端） | 赫布式局部更新（活动相关） |

**判定**：前向传播的「等权→加权」对齐 ✅，但 GAT 的权重来自学习，海波需要局部计算来源 ⚠️。

### A3 差异分析

| 维度 | GAT | 海波语义图 |
|------|-----|-----------|
| **注意力权重来源** | `a` 和 `W` 通过反向传播学习 | 必须来自局部可计算信号（共现/激活/转移概率） |
| **参数可训练性** | ✅ 全部可训练 | ❌ 无参数可训练 |
| **是否需要标签** | ✅ 需要（交叉熵损失） | ❌ 完全不需要 |
| **权重可解释性** | α_ij 可解释，但 a 和 W 黑箱 | w_ij 是语义关联强度，完全可解释 |
| **邻居范围** | 一阶邻居（含自环） | 一阶邻居（当前无自环） |
| **多视角** | K 个可训练注意力头 | 无多视角（单头围合） |
| **图结构要求** | 无向/有向均可（α_ij ≠ α_ji） | 无向（当前对称权重） |
| **计算模式** | 全图前向传播（直推式）或逐图（归纳式） | 局部子图激活（单概念触发） |
| **训练数据量** | 需要大量标注或半标注数据 | 零标注 |
| **动态图支持** | 有限（新节点需重新计算注意力） | 天然支持（每次交互激活不同子图） |

**判定**：差异集中在**权重来源**这一根本问题上。GAT 的权重来自数据驱动的监督学习，海波的权重必须来自模型驱动的局部计算。前向传播的形式可以借鉴 ⚠️，但 GAT 的训练范式完全不可用 ❌。

---

### A4 改造方案

#### 方案 A：多头围合（从单头到 K 头，低风险，4 小时）

将当前的单头围合扩展到 K 头并行，每个头从不同"概念视角"计算围合得分。

```python
# 当前单头围合
def enclosure_score(v, graph):
    return sum(graph.edge_weight(v, u) * activation[u] for u in neighbors(v))

# 改造：多头围合
def multihead_enclosure(v, graph, heads=4):
    scores = []
    for head in range(heads):
        if head == 0:  # 头1：共现频率视角
            weights = cooccurrence_weights(v, graph)
        elif head == 1:  # 头2：义原语义相似度视角
            weights = sememe_similarity_weights(v, graph)
        elif head == 2:  # 头3：上下文激活强度视角
            weights = activation_intensity_weights(v, graph)
        elif head == 3:  # 头4：转移概率（随机游走）视角
            weights = transition_prob_weights(v, graph)
        
        head_score = sum(weights[u] * activation[u] for u in neighbors(v))
        scores.append(head_score)
    
    # 最后一层平均（类似 GAT 最后一层的多头平均）
    return mean(scores)
```

**优点**：
- 每个头的权重来源都是局部可计算的（共现/相似度/激活/转移概率）
- 不需要反向传播，完全符合海波方法论
- 不同头捕捉不同关系类型，互补性好
- 可以直接扩展到 8 头或更多

**风险**：
- 头数太多可能引入噪声
- 需要确定哪些"概念视角"是真正互补且有区分度的
- 头之间的权重尺度可能不一致，需要归一化

**验证**：在消歧任务上比较单头 vs K=2,4,8 头的准确率

**预期**：K=4 或 K=8 时效果最优，超过 8 后收益递减

---

#### 方案 B：注意力式围合 — 基于激活模式计算邻居权重（中等风险，1-2 天）

借鉴 GAT 的注意力思想，但用赫布式局部计算代替反向传播——通过当前激活模式来计算每个邻居的重要性权重。

```python
# GAT 式注意力（但无训练参数）
def attention_enclosure(v, graph):
    # 计算 v 和每个邻居 u 的「激活相似度」
    # 注意力 = 两个概念的嵌入相似度 × 当前激活强度
    raw_attention = {}
    for u in neighbors(v):
        # 使用概念嵌入（HowNet sememe vector 或 LLM embedding）的余弦相似度
        sem_sim = cosine_sim(embedding[v], embedding[u])
        # 乘以邻居的当前激活强度
        raw_attention[u] = sem_sim * activation[u]
    
    # Softmax 归一化（局部化）
    denom = sum(exp(a) for a in raw_attention.values())
    alpha = {u: exp(a) / denom for u, a in raw_attention.items()}
    
    # 加权聚合
    score = sum(alpha[u] * activation[u] for u in neighbors(v))
    return score
```

**优点**：
- 形式上非常接近 GAT（注意力系数 + 加权聚合）
- 权重来自「嵌入相似度 × 激活强度」，完全是局部计算
- 不需要任何训练或标签

**风险**：
- 嵌入质量决定注意力质量——HowNet 义原嵌入可能不够区分细粒度语义
- softmax 归一化在小邻域（<5 节点）可能不稳定
- 嵌入相似度 ≠ GAT 学到的注意力，不能保证等价效果

**验证**：在不同嵌入质量下比较 attention_enclosure 和 baseline 的效果

#### 方案 C：多头注意力的结构化头分配（中等风险，1 天）

在方案 A 基础上添加**结构化头分配**——不同头不是随机视角，而是对应不同的语义关系维度。

```python
# 结构化多头围合
STRUCTURED_HEADS = {
    'hypernym': lambda v, u: is_hypernym(v, u),        # 上位关系
    'hyponym': lambda v, u: is_hyponym(v, u),           # 下位关系
    'cooccur': lambda v, u: cooccur_freq(v, u),         # 共现频率
    'attribute': lambda v, u: is_attribute(v, u),        # 属性关系
    'partof': lambda v, u: is_part_of(v, u),             # 部分-整体关系
    'context_sim': lambda v, u: context_similarity(v, u),# 上下文相似度
    'sememe_overlap': lambda v, u: sememe_overlap(v, u), # 义原重叠度
    'transition': lambda v, u: transition_prob(v, u),    # 随机游走转移概率
}

def structured_multihead_enclosure(v, graph):
    scores = []
    for head_name, head_fn in STRUCTURED_HEADS.items():
        weights = {u: head_fn(v, u) for u in neighbors(v)}
        # 归一化
        total = sum(weights.values())
        if total > 0:
            weights = {u: w/total for u, w in weights.items()}
        head_score = sum(weights[u] * activation[u] for u in neighbors(v))
        scores.append(head_score)
    
    return mean(scores)  # 或加权平均（可调各头的权重）
```

**优点**：
- 每个头有明确的语义意义（不是黑箱），完全可解释
- 8 个头对应 8 种语义关系，覆盖 HowNet 的义原关系体系
- 每个头的计算都是局部的、赫布式的

**风险**：
- 有些关系（如 partof / attribute）在海波的语义图中不一定存在
- 需要预先定义头结构和关系映射，灵活性不如 GAT 的端到端学习
- 头数固定（8），如果某些关系在实际数据中不活跃，这些头就是无效的

**验证**：分析各头在消歧任务中的贡献度——那些头总是给出相似得分（冗余），那些头在特定场景下主导决策（特异性）。

### A6 一句话决策

> **GAT 对海波的核心启发不是「注意力网络」本身，而是「差异化邻居权重」和「多头融合」这两个设计思路——前者可以用激活模式计算替代反向传播（R2），后者可以直接迁移（R1）；GAT 的可训练参数和端到端训练范式与海波方法论根本对立，绝不能混入。**
