# 认知语言学

> 概念形成、隐喻、原型理论、心理空间

---

## 关键理论家

### [[literature/cog-ling/barsalou-perceptual-symbols|Barsalou — 知觉符号理论（1999）]]
概念 = 感知-运动系统的神经重激活，不是抽象符号。
→ 感知词（甜、香、音质）有更强的诊断性。

### [[literature/cog-ling/lakoff-metaphor|Lakoff — 概念隐喻理论]]
人类的抽象概念通过身体经验的具体隐喻来组织。
→ "更多是向上"、"时间是空间"

### [[literature/cog-ling/rosch-prototype|Rosch — 原型理论]]
概念不是有清晰边界的集合，而是围绕原型组织的。
→ "鸟"的原型是麻雀，不是企鹅

## 对 Haibo 的价值

- Barsalou → H-SG-2 节点固化的认知基础，感知特征权重的理论支撑
- Rosch → 概念节点的模糊边界和原型效应
- Lakoff → 隐喻关系的建模
