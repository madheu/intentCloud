# 核心理念

> **语言不是思维本身，是思维在低维空间的投影。**

---

## 核心主张

语言（自然语言文本）是思维在低维空间的**投影**。真正的语义结构存在于高维概念空间中，而自然语言只是这个空间的降维表示。

## 对 Haibo 设计的含义

1. **不能直接对词操作** — 词是投影后的符号，不是概念本身
2. **需要概念层** — Semantic Node 是概念空间中的稳定结构
3. **消歧 = 找到投影的逆映射** — 同一词在不同语境中投影到不同概念

## 理论来源

- 认知语言学：Langacker 的认知语法
- Barsalou 的知觉符号理论
- NLP 中的表示空间研究
