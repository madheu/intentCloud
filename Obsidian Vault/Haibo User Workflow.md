## 角色扮演规范

- 我被指定为某个角色时（PI / Cognitive Scientist / Control Scientist / AI Reviewer），**必须完整进入角色直接执行任务**，不要写提示词给"自己"
- 每次输出要指定收件人角色和范围
- 审查委员会 5 角色：PI（首席研究员）、Cognitive Scientist、Control Scientist、AI System Reviewer、Research Executor

## 核心工作流

```
PI 定方向
  ↓
我（Research Engineer/执行者角色）拆解为最小可验证任务
  ↓
写完整执行者指令（含：背景→步骤→预期结果→通过/失败标准→输出格式）
  ↓
发给执行者跑实验（我不直接动手）
  ↓
我看数字 → PI 判断 → 记录决策
```

### 关键约束
- 改一行代码 → 跑一次 → 看两个数字
- 善用控制问题引导方向
- 精确实验闭环驱动研究判断
- 不要自己动手跑实验，也不要只写模糊的描述

## 实验方法论

### P0 系列范式
```
可证伪假设
  ↓
最小实现
  ↓
控制实验（词袋基线→逐层复杂度递增）
  ↓
盲测验证
```

### 实验设计原则
1. **先跑 pilot**（1 条件 × 10 seed）校验工具可用性
2. **控制组必须和实验组同源**
3. **MFS 基线先行**：从开发集算，不泄露进盲测
4. **predict.py 和 score.py 分离**
5. **各层多样性自检**：单标签 → 终止
6. **目标锚定用字符 span**，不全句扫歧义词
7. **诚实报告失败** > 正面结论

### 数据驱动决策
- 决策基于量化结果（MI / class ratio / confidence / accuracy）
- 实验证伪不纠结，直接换路线
- P0 系列记录了 7 个 falsification 链

## 技术偏好

### 语义设计
- 图节点=概念（科技类/水果类），不=词Token
- 词→概念是归属关系
- 结构化解题思路："每超过四个维度就向外拓展一层，每次只比四个"（P_Resolve-10 验证）
- 不重新发明语义分类学，用已有理论（FrameNet / HowNet / Semantic Role）

### 语言/NLP
- 不做 jieba 整词过滤（破坏单字歧义词：花/光/行/口）
- POS 分层过滤：保留名词动词，过滤虚词副词
- 单字名词/动词是有效语义载体
- "不确定"是有效输出，语义歧义应被明确承认

### LLM 使用策略
- 用最强 LLM 做**研究顾问**（审实验→诊断瓶颈→提方案），不只是数据生成工具
- ChatGPT / DeepSeek 用于非结构化概念讨论
- 执行者（Research Executor）负责跑实验

### 实验数据资源
- RTX 4060 8GB
- 腾讯 200d 词向量
- HowNet / OpenHowNet
- LLM 生成 2100 句训练数据（`p0_b2_llm_contexts.json`）

### 工作流细节

- 偏好 [ A / B ] 选择题模板
