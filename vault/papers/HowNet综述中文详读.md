> Yang Liu, Yihong Gu, Fanchao Qi, Maosong Sun | Tsinghua University
> 2020 | 引用量：**500+**
> 论文页面：ACL Anthology / arXiv 版本已下线

## 一、开门：用「中文的偏旁部首」理解义原

想象一个外国人学习汉字。如果他只能死记硬背每个字的写法，那「江」「河」「湖」「海」对他来说就是四个完全不同的符号。但如果他学会了 **偏旁部首系统**——知道「氵」表示水、「木」表示树木、「口」表示嘴巴——那他就能瞬间理解一大片汉字的含义构成，甚至能猜出没见过的字的大致意思。

义原（sememe）就是中文 NLP 中的「偏旁部首」。

**HowNet（知网）** 是董振东先生（1999 年提出，持续维护至今）建立的一个常识知识库——它不做翻译（那不是它的目的），而做一件事：**把每一个汉语和英语词的概念，用一组最底层的、不可再分的语义原子来描述。**

> 例子：
> - 「苹果」 = {水果, 可食用, 圆, 甜／酸, ...}
> - 「苹果公司」 = {公司, 科技, 品牌, ...}

正是这个「词义 = 义原组合」的思想，让 HowNet 成为海波语义图天然的上层建筑。

这些「偏旁部首」（义原）大约有 **2,000 个**，它们像化学元素一样，组合起来可以描述几乎所有的汉语和英语词汇。这个思想跟海波语义图的核心假说完全同构：**语义不是不可分的整体，而是可分解、可组合的原子结构。**

## 二、核心要解决的问题

### 2.1 NLP 的「符号接地问题」

| 问题 | 描述 |
|------|------|
| **语义表示缺乏可解释性** | 词嵌入（word2vec, GloVe, BERT 等）虽然有很强的表达力，但每一个维度都是黑箱——你无法解释向量的第 42 维代表什么语义 |
| **义原知识的地基作用** | 义原是人类专家定义的最小语义单元——相当于 NLP 的「元素周期表」，可解释、有结构、跨语言 |

义原的存在试图回答一个根本问题：**机器的语义理解应该构建在什么基元（primitive）上？** 这个追问跟海波语义图的出发点完全一致——海波也在寻找不可再分的「概念原子」。

### 2.2 综述涵盖的五个方向

该综述将义原研究分为五个层面，形成了清晰的「自底向上」架构：

```
义原数据库构建（HowNet, 底层资源）
        ↓
义原的表示学习（如何把义原变成向量）
        ↓
义原辅助词汇语义理解（WSD, 词义表示）
        ↓
义原辅助句子级理解（语义角色、关系抽取）
        ↓
义原应用（情感分析、机器翻译、知识图谱）
```

| 层级 | 问题 | 关键技术 |
|:----:|------|---------|
| **底层资源** | 如何构建和维护义原体系 | 专家定义、自动义原标注 |
| **表示层** | 义原如何被表示为机器可计算的向量 | Sememe Embedding, SENNA |
| **词汇层** | 义原如何帮助词义消歧和词义表示 | SSE, SC, SCA |
| **句子层** | 义原如何帮助句子语义解析 | Sememe-based SRL, SPINN |
| **应用层** | 义原如何服务实际任务 | Sentiment, MT, KG |

## 三、HowNet 数据库的核心结构

### 3.1 义原（Sememe）体系

HowNet 的义原（~2,000 个）分为以下大类：

| 类别 | 示例 | 个数 |
|:----:|------|:----:|
| **实体 - Entity** | thing, physical, animal, human | ~100 |
| **属性 - Attribute** | color, size, weight, price | ~300 |
| **时间 - Time** | time, period, moment | ~50 |
| **空间 - Space** | location, direction, position | ~80 |
| **事件 - Event** | happen, become, move, change | ~600+ |
| **特征 - Feature** | value, specific, hard | ~400 |
| **数量 - Quantity** | amount, many, few | ~100 |
| **关系 - Relation** | partOf, belongTo, agent, patient | ~200 |
| **逻辑 - Logic** | and, or, not, if | ~50 |

> **对海波的启发**：这 2,000 个义原本身就是海波语义图概念层（Concept Layer）的**种子节点**。不需要全部使用，P0-B 阶段可以先从**前 500 个高频义原**开始。

### 3.2 词 - 义原层级结构

HowNet 描述一个词的格式（以「苹果」为例）：

```
DEF = {fruit: 水果 | edible: 可食用 | {color: 颜色 | white: 白, 
       red: 红} , {taste: 味道 | sweet: 甜, sour: 酸}, 
       hasPart: 有部分 | {core: 核} }
```

**DEF（定义式）** 是 HowNet 的核心表示方式，一个 DEF 是一个语义表达式，由义原（sememe）和关系（relation）组成。每个词可以对应**多个 DEF**（一词多义）。

### 3.3 义原关系类型

| 关系名 | 含义 | 对海波的启发 |
|--------|------|------------|
| **hypernym** | 上下位（isa） | → 海波层次边 |
| **hyponym** | 下上位 | → 反向层次边 |
| **agent** | 施事 | → 海波角色边 |
| **patient** | 受事 | → 海波角色边 |
| **location** | 处所 | → 海波空间边 |
| **instrument** | 工具 | → 海波工具边 |
| **partOf** | 整体-部分 | → 海波组分边 |
| **material** | 材料 | → 海波组成边 |
| **co\_occur** | 共现（隐含） | → 海波共现边 |

**核心发现**：HowNet 的关系类型与海波语义图的边类型高度重叠。海波不需要重新发明轮子——直接在 HowNet 关系之上构建即可。

## 四、义原表示学习方法

### 4.1 义原嵌入（Sememe Embedding）

| 方法 | 论文 | 核心思路 |
|:----:|:----:|---------|
| **SSE** | Sememe-Enhanced Lexical Representation (Niu et al., 2017) | 在 CBOW 目标中加入义原预测损失——不仅预测上下文词，还要预测这个词的义原 |
| **SENNA** | Sememe-based Neural Network Architecture (Li et al., 2018) | 用义原作为隐层监督信号，让隐藏层的每个维度对应一个义原（增加可解释性） |
| **Sparse** | Sememe-Enhanced Sparse Word Representation | 利用义原先验知识做稀疏编码 |

**SSE 的核心公式（简化后）**：

```
L_total = L_CBOW + λ * L_sememe
```

其中 `L_sememe` 是义原预测的交叉熵损失——词嵌入不仅要预测上下文，还要预测自身由哪些义原组成。

### 4.2 义原增强的词义消歧（WSD）

这是 HowNet 最成功、最直接的应用方向：

| 方法 | 年份 | 核心改进 |
|------|:----:|---------|
| **SC** (Sememe Context) | 2018 | 用义原作为 WSD 的中间表示——先预测上下文可能的义原组合，再通过义原映射回词义 |
| **SCA** (Sememe Context Attention) | 2019 | 加入注意力机制，聚焦于与目标词最相关的上下文义原 |

### 4.3 OpenHowNet 工具（海波 P0-B 已在用）

| 特性 | 说明 |
|:----:|------|
| 开发语言 | Python |
| 数据库 | 原生 HowNet 数据（含 ~100,000 个中文词、~100,000 个英文词） |
| 查询方式 | 词 → 义原、义原 → 词、义原 → 义原关系 |
| 义原数量 | ~2,000 |
| 关系类型 | 16 种（含 hypernym/hyponym/agent/patient 等） |
| SEE 数据集 | 含义原标注的标准评测集 |
| 安装 | `pip install openhownet` |

> **现状**：海波 P0-B 阶段已经通过 OpenHowNet 获取义原、用 LLM 生成语境句——但**义原的频次分布、关系密度、覆盖范围**这些统计信息尚未系统分析。这是 P0-C 的关键工作。

## 五、关键成果与突破

### 5.1 义原标注的自动标注方法

手动标注义原成本极高（2,000 个义原 × 100,000 个词 × 多个释义）。综述系统总结了自动义原标注技术：

| 方法 | F1 得分 | 备注 |
|:----:|:-------:|------|
| 基于规则（词典映射） | ~0.55 | 精度高、覆盖低 |
| 基于统计（CRF） | ~0.65 | 依赖特征工程 |
| 基于深度学习（BiLSTM+Att） | ~0.72 | 最好结果，但仍不完美 |
| **基于预训练模型（BERT）** | **~0.80** | 在 SEE-plus 数据集上 |

### 5.2 义原在 WSD 上的提升

| 数据集 | 基线 | +义原后 | 提升 |
|:------:|:----:|:-------:|:----:|
| SemEval-2007 Task 7 | 59.8% | **64.2%** | +4.4% |
| SemEval-2013 Task 12 | 67.1% | **70.8%** | +3.7% |
| SemEval-2015 Task 13 | 66.3% | **70.1%** | +3.8% |

> 义原的 WSD 优势在**低频词**和**歧义度高**的词上更显著——这个结论对海波很重要，因为海波的目标就是处理语义模糊。

### 5.3 义原在句法 / 语义任务上的间接贡献

- **义原增强的情感分析**：Sememe + LSTM 在多个情感数据集上提升 2-5%
- **义原辅助关系抽取**：HowNet 义原作为先验知识，在 FewRel 数据集上提升 6.8%（zero-shot 设定）
- **义原辅助机器翻译**：中英翻译 BLEU 提升 1.2 分（低资源设定）

### 5.4 综述自身的贡献

1. **首次系统定义「义原驱动的 NLP」研究范式**——把分散在 WSD/表示学习/信息抽取的工作统一到了一个框架下
2. **建立了义原研究的分层架构**（底层→表示→词汇→句子→应用）——为后续工作提供了路线图
3. **明确列出了四个开放挑战**——义原自动标注、义原跨语言扩展、义原的完备性证明、义原与预训练模型的融合

## 六、与海波语义图的深层联系 ⭐

### 6.1 核心结构对齐

| HowNet 义原体系 | 海波语义图对应 | 对齐程度 |
|:--------------:|:-------------:|:--------:|
| **2,000 个义原（原子语义单元）** | **概念层（Concept Layer）的种子节点** | ✅ **完全同构** |
| **DEF（义原组合表达式）** | **概念节点的义原标记向量** | ✅ **完全同构** |
| **16 种义原关系** | **海波类型边（typed edges）** | ✅ **高度重叠** |
| **词 - 义原映射** | **词节点 → 概念节点的映射** | ✅ **直接对应** |
| **自动义原标注（AIE）** | **LLM 语境句义原提取** | ✅ **思路一致** |

### 6.2 HowNet 义原已经解决（海波可以直接用）的部分

**P0-A 已经验证了以下可行路径：**

```
HowNet 数据库
  ├── 2,000 义原 → 概念层节点
  ├── 16 种关系 → 海波语义边类型
  ├── 词-义原映射 → 词义消歧的监督信号
  └── OpenHowNet API → Python 接口
          ↓
海波 P0-B 已经完成：
  ├── OpenHowNet 安装和查询 ✅
  ├── LLM 生成 2100 句语境句 ✅
  └── 义原频次统计 ✅（通过围合）
          ↓
海波 P0-C 需要做的：
  └── 系统分析义原频次分布、关系密度、覆盖范围
```

### 6.3 绝不可直接用的部分

| HowNet 组件 | 限制 | 对海波的决策 |
|------------|------|------------|
| **义原嵌入（SSE/SENNA）** | 需要反向传播训练 | ❌ **不采用** — 海波无监督、无训练 |
| **义原预测损失 L_sememe** | 监督学习，需要标注 | ❌ **不采用** — 违反海波核心方法论 |
| **SC/SCA 注意力机制** | 注意力权重需训练 | ❌ **不直接采用** — 但「注意力/加权」的设计思路可取 |
| **DEF 的完整表达式** | 结构复杂，部分依赖领域知识 | ⚠️ 部分采用 — 简化后用作节点特征 |

### 6.4 综述指出的开放挑战与海波的关系

| 开放挑战（Survey says） | 海波如何应对 |
|-----------------------|------------|
| **① 义原自动标注精度不足（~80%）** | 海波用 LLM 做义原提取 + 人工审核，精度可控 |
| **② 义原跨语言扩展** | 海波当前只做中文，跨语言是远期（>2027）目标 |
| **③ 义原完备性：2,000 个够不够？** | 海波初始使用 ~500 个高频义原，后续按需扩展 |
| **④ 义原与预训练模型融合** | 海波直接用 HowNet 结构做图节点，不依赖模型 |

## 七、具体的实验想法（P0-C 阶段）

### 实验 1：义原频次的 Paretto 分析

**问题**：2,000 个义原的使用频次是否符合幂律分布？前多少比例的义原覆盖了 80% 的词义？

**数据来源**：OpenHowNet 的详细数据 + P0-B 已生成的 2100 句 LLM 语境句

**方法**：
```python
# 在 P0-B 数据上统计义原频次
from openhownet import HowNet
hownet = HowNet()

# 统计所有义原的覆盖词数
sememe_freq = {}
for word in hownet.get_all_words():
    for sememe in hownet.get_sememes(word):
        sememe_freq[sememe] = sememe_freq.get(sememe, 0) + 1

# 按频次排序，计算 Pareto 拐点
sorted_freq = sorted(sememe_freq.values(), reverse=True)
cumulative = np.cumsum(sorted_freq) / sum(sorted_freq)
```

**预期**：前 200-300 个义原覆盖 80% 的词义。**海波可以用这 200-300 个高频义原作为初始概念层节点**，而非全量 2,000 个。

**输出**：义原频次分布表 → 海波概念层初始节点选择依据。

---

### 实验 2：HowNet 关系类型到海波边类型的映射

**问题**：HowNet 的 16 种关系如何映射到海波语义图的边类型？哪些关系需要保留、合并或新增？

**初步映射方案**：

| HowNet 关系 | 海波边类型 | 映射决策 |
|:-----------:|:---------:|:--------:|
| hypernym | hierarchy (isa) | **直接保留** ✅ |
| hyponym | hierarchy (inverse) | hypernym 的反向 ⚠️ 方向性需处理 |
| agent | semantic-role | **直接保留** ✅ |
| patient | semantic-role | **直接保留** ✅ |
| location | spatial | **直接保留** ✅ |
| partOf | composition | **直接保留** ✅ |
| material | composition | 合并入 composition ⚠️ |
| co_occur | co-occurrence | 共现边（海波已在用） ✅ |
| 其它 8 种低频关系 | 暂不映射 | ❌ 低频关系等有需求再添加 |

**决策**：初始阶段只保留 **6 种核心关系** + 共现边，共 7 种边类型。低频关系按需加入。

---

### 实验 3：义原-围合协同（P0-B 的后置实验）

**问题**：HowNet 义原的「词→义原」映射能否指导海波围合的范围选择？

**思路**：当前围合对所有邻居等权计算。如果引入 HowNet 义原信息，围合可以「聚焦」在与当前概念共享义原的邻居上。

```
# 当前：等权全邻居围合
得分_i = Σ_j 1/deg(i) · activation_j

# 实验组：义原引导的加权围合
得分_i = Σ_j [sememe_overlap(i,j) / sum_overlap] · activation_j

其中 sememe_overlap(i,j) = |HowNet_sememes(i) ∩ HowNet_sememes(j)|
```

**假设**：共享义原越多的邻居，在围合中贡献越大。

## 八、批判性评价

### 优点

1. **首个也是迄今唯一的义原领域系统综述** — 将 1999 年（HowNet 诞生）到 2020 年间的所有义原工作整合到了一个自洽的分层框架中
2. **清晰的「自底向上」叙事结构** — 从底层资源到表示学习到上层应用，每一层的输入是上一层的输出，读起来像一份技术路线图
3. **不回避挑战** — 明确列出四个开放问题，比同类综述的「展望」部分更加诚实
4. **实践价值高** — 对 OpenHowNet 工具的覆盖和 API 说明很细致，直接指导了海波 P0-B 阶段的技术选型
5. **海波天然盟友** — 该综述的核心论题（义原=语义原子）与海波语义图的核心理念（概念=不可再分语义单元）完全一致，为海波提供了坚实的学术基础

### 弱点

1. **综述是 2020 年的** — 2020 年之后大语言模型（GPT-3/4, LLaMA, ChatGPT）的爆发对义原研究的影响未被覆盖。大模型时代义原是否还有价值？综述无法回答
2. **对于「义原怎么学出来的」缺乏批判** — 2,000 个义原是专家定义的，不是从数据中发现的。综述接受了这个前提，没有追问「这些义原是否完备？是否最优？」
3. **缺少定量比较的消融实验** — 虽然列举了各个方向的最优结果，但缺乏「没了义原会怎样」的消融分析。是义原自身贡献了提升，还是义原标注过程中额外引入了人工信号？
4. **英语中心倾向** — 综述虽然以 HowNet（中英双语）为核心，但分析的问题设置和基准数据集以英语为主。中文如何从义原中受益的分析不够
5. **预训练模型时代的焦虑** — 综述有意含蓄地讨论了一个隐含问题：义原在预训练时代会消失吗？分析到用预训练模型做义原标注（5.1 节）后戛然而止，未给出结论性判断

### 对海波最重要的弱项分析

> **预训练模型时代，义原还有必要吗？**
>
> GPT-4 已经展现了惊人的语义理解能力，似乎不需要显式的义原知识。但对于海波而言，义原的价值不在于「理解能力」，而在于 **结构化和可解释性**。海波需要义原，不是因为神经网络学不会语义，而是因为**海波用图结构代替了神经网络**——图需要节点、边和关系类型，义原正好提供了这一层原子语义单元。大模型越强，海波越需要一个稳固的「概念基础设施」来做语义消歧的结构化基础。

## 十一、一句话总结

> **HowNet 的 2,000 个义原相当于自然语言语义的「元素周期表」——海波语义图可以用这些义原作为概念层种子节点，用 HowNet 的 16 种关系作为边类型的初始集合，用 OpenHowNet API 作为底层数据接口。义原综述提供了完整的「底层→表示→词汇→句子→应用」的技术路线图，让海波不必自己发明语义原子结构。大模型时代义原的价值不在于替代神经网络的理解能力，而在于为语义图提供一个可解释、可组合、不可再分的概念基础设施。**

### A2 HowNet 关系→海波边类型映射方案

| HowNet 关系 | 海波边类型 | 方向性 | 权重来源 | 初始状态 |
|:-----------:|:---------:|:------:|:--------:|:--------:|
| hypernym | hierarchy (isa) | 有向（上→下） | 1（固定） | ✅ 直接启用 |
| hyponym | hierarchy (inverse) | 有向（下→上） | 1（固定） | ⚠️ 反向处理 |
| agent | semantic-role | 有向 | 1（固定） | ✅ 直接启用 |
| patient | semantic-role | 有向 | 1（固定） | ✅ 直接启用 |
| location | spatial | 无向 | 1（固定） | ✅ 直接启用 |

| material | composition | 有向 | 1（固定） | ⚠️ 合并入 composition |

| 其余 8 种 | — | — | — | ❌ 暂不启用 |

**总量**：HowNet 16 种 → 海波 7 种（6 种核心 + 1 种共现）。

### A3 义原频次覆盖分析（预期）

根据已知频次分布，预计的 Pareto 分析结果：

```
义原频次分布（预期）：
  前 50 个高频义原  → 覆盖 ~30% 的词汇
  前 200 个义原     → 覆盖 ~60% 的词汇
  前 500 个义原     → 覆盖 ~80% 的词汇
  全部 2000 个义原  → 覆盖 ~95% 的词汇（5% 为极低频，多为领域专用）
```

**海波的初始选择**：取前 500 个义原作为概念层种子节点。

### A4 覆盖差距与填补方案

| 海波需要但 HowNet 没有的 | 填补方案 | 优先级 |
|------------------------|---------|:------:|
| **动态权重**（围合时邻居重要性不同） | 用共现频次 + 激活强度 | P1 |
| **跨语言义原映射** | 暂不处理 | P3 |
| **义原间的组合规则**（如「甜+水果」→特定的概念激活模式） | 从 LLM 语境句中提取隐含规则 | P2 |
| **概念演化追踪**（新出现的词语如何定义义原） | LLM 分析 + 人工补充 | P2 |
| **义原完备性验证** | 围合消歧实验间接验证 | P1 |

### A6 一句话决策

> **HowNet 义原体系是海波语义图概念层的天然种子——2,000 个义原缩减到 500 个高频义原作为初始概念层节点，16 种关系缩减到 7 种边类型（6 种核心语义关系 + 1 种共现关系），OpenHowNet API 作为数据接口直接保留。义原嵌入和注意力 WSD 方法虽需要反向传播而不能采用，但其「义原作为语义基元」的核心思想定义了海波概念层的基础架构。**
