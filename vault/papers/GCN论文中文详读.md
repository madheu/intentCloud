> **Semi-Supervised Classification with Graph Convolutional Networks**（图卷积网络半监督分类）
> Thomas N. Kipf & Max Welling | University of Amsterdam / CIFAR
> ICLR 2017 | arXiv:1609.02907 | 引用量：**30,000+**

---

## 一、开门：用"朋友圈猜性格"理解 GCN

想象你刚搬进一个新小区，不认识任何人。你想知道你的邻居们是什么性格，但只能问到其中几个人。

怎么办？一个直觉是：**朋友相似的人，性格也可能相似。** 如果你观察到小王经常和小李、小张一起打球，而你恰好知道小李和小张都很外向，那你就可以合理推断小王也很外向。

GCN 做的就是这件事——但它更进一步：不仅仅看朋友的朋友，还看**每个朋友自己带了多少"特征信息"**。它不像传统方法只假设"相连的节点应该标签相似"，而是让**邻居的特征信息像水波一样在图上扩散、汇聚，然后学到一个新表示**。

这个"水扩散"的过程（消息传递 / message passing），跟海波语义图的**激活扩散**非常相似——区别在于 GCN 用全局反向传播训练（需要标签），而海波用的是赫布式局部学习（无监督）。

---

## 二、核心要解决的问题

| 问题 | 描述 |
|------|------|
| **半监督节点分类** | 图上只有少数节点有标签，要为所有无标签节点分类 |
| **图结构编码** | 传统的图拉普拉斯正则化（Eq.1）假设"边=相似性"，但这个假设太强，限制了模型容量 |
| **计算效率** | 谱图卷积需要 O(N²) 特征分解，完全不可扩展 |

GCN 的核心贡献就是用**一阶近似**把谱图卷积降到 O(|E|)（与边数线性相关），让图网络真正可用。

---

## 三、核心方法

### 3.1 从谱图卷积到一阶近似（三层简化）

GCN 的方法论是一层一层"做减法"的典范：

**第1层：Chebyshev 近似（Defferrard et al., 2016）**

谱图卷积原始公式涉及拉普拉斯矩阵的特征分解（O(N²)），不可行。Chebyshev 多项式截断到 K 阶后：

```
gθ' ⋆ x ≈ Σ θ'k Tk(˜L) x ,   复杂度 O(|E|)
```

**第2层：K=1 的一阶近似**

Kipf & Welling 更进一步，限制 K=1——每层只考虑直接邻居。这样可以堆叠多层来获得多跳信息，同时每层参数极少，防止过拟合：

```
gθ' ⋆ x ≈ θ'0 x + θ'1 (L - I) x
```

**第3层：参数共享 + 重整化（renormalization trick）**

进一步令 θ = θ'0 = -θ'1，得到单参数版本：

```
gθ ⋆ x ≈ θ (I + D^{-1/2} A D^{-1/2}) x
```

但 I + D^{-1/2} A D^{-1/2} 的特征值范围是 [0, 2]，深层堆叠会导致数值不稳定。关键技巧来了——**重整化（renormalization trick）**：

> **ÌN + D^{-1/2} A D^{-1/2} → ˜D^{-1/2} ˜A ˜D^{-1/2}**

其中 ˜A = A + I_N（加自环），˜D 是 ˜A 的度矩阵。这样特征值被限制在 [-1, 1]，训练更稳定。

### 3.2 两层 GCN 的完整前向传播

```
Z = softmax( ˆA · ReLU( ˆA · X · W⁰ ) · W¹ )
```

其中 ˆA = ˜D^{-1/2} ˜A ˜D^{-1/2} 是预处理好的归一化邻接矩阵。

| 符号 | 含义 | 维度 |
|------|------|------|
| X | 节点特征矩阵 | N × C |
| W⁰ | 输入→隐藏层权重 | C × H |
| W¹ | 隐藏层→输出权重 | H × F |
| ˆA | 对称归一化邻接矩阵 | N × N（稀疏） |
| Z | 输出（softmax 后为类概率） | N × F |

### 3.3 训练方式

- 损失函数：仅在有标签的节点上计算交叉熵（半监督）
- 优化器：Adam（lr=0.01）
- 正则化：Dropout + L2 正则（第一层权重）
- 全批量梯度下降（当时数据集可放内存）
- 早停（validation loss 连续 10 轮不降则停）

> ⚠️ 这一点对海波至关重要：**GCN 的"半监督"意味着它依赖少量标签 + 大量无标签数据 + 反向传播。海波没有任何标签，也不能用反向传播。**

## 五、与海波语义图的深层联系 ⭐

### 5.1 图结构上的同构

```
GCN 的消息传播：        h_i^{(l+1)} = σ( Σ_j 1/c_ij · h_j^{(l)} · W^{(l)} )
                           ↓
海波的激活扩散：        activation_i(t+1) = f( Σ_j w_ij · activation_j(t) )
```

两种方法都做同一件事：**节点从邻居汇聚信息，更新自己的状态**。GCN 用归一化邻接矩阵 ˆA 做线性组合，海波用赫布权重 w_ij 做激活传播。形式上几乎一样。

### 5.2 GCN 的 WL 图同构解释

论文附录 A 揭示了 GCN 与 **Weisfeiler-Lehman（WL）算法**的关系——这是图同构测试的标准方法。WL 通过迭代聚合邻居标签（哈希）来区分图结构：

```
WL 算法：            h_i^{(t+1)} = hash( Σ_j h_j^{(t)} )
GCN（向量版本）：    h_i^{(l+1)} = σ( Σ_j 1/c_ij · h_j^{(l)} · W^{(l)} )
```

GCN 本质上是**可微分的 WL 算法推广**。这意味着即使未经训练的 GCN（随机权重）已经可以提取有意义的图结构特征——论文用 Zachary karate club 网络展示了这一点。

**对海波的启发**：海波的围合（enclosure）计数本质上也是在检测局部图结构模式。WL 同构测试的思路可能为围合提供一种更系统的数学框架。

### 5.3 关键差异：监督 vs 无监督

| 维度 | GCN | 海波语义图 |
|------|:---:|:----------:|
| 训练信号 | 标签交叉熵（反向传播） | 赫布式局部学习（无监督） |
| 权重更新 | 全局梯度下降 | 局部活动相关 |
| 是否需要标签 | ✅ 半监督需要标签 | ❌ 完全不需要 |
| 权重含义 | 过滤器参数，不可解释 | 节点间关联强度，可解释 |
| 可解释性 | 隐藏层是黑箱 | 全节点透明 |

这张表是最重要的——**任何把 GCN 整建制搬到海波的企图都不可行**，因为训练机制根本不同。

### 5.4 可以借用的东西

| 借鉴点 | 怎么用 | 优先级 |
|--------|--------|:------:|
| **邻居聚合规范化** | ˆA = ˜D^{-1/2} ˜A ˜D^{-1/2} 这个归一化技巧比海波目前用的原始度归一化更稳定 | ⭐⭐⭐ |
| **层式传播（layer-wise propagation）** | 堆叠多层激活扩散可以捕获高阶语义邻域，海波目前只有一层 | ⭐⭐⭐ |
| **重整化技巧** | 把自环加入邻接矩阵然后归一化，防止度大的节点主导激活 | ⭐⭐ |
| **WL 同构框架** | 为围合计数提供图论理论基础 | ⭐⭐ |
| **随机权重特征提取** | 未经训练的 GCN 也能抽取图结构特征——海波可以借鉴这一点减少对初始权重的依赖 | ⭐ |

### 5.5 绝对不能借用的东西

- ❌ **反向传播（backpropagation）**：这一条是铁律。海波的核心创新就是赫布式局部学习代替全局梯度下降
- ❌ **全批量训练**：GCN 把整个图放进内存做一次前向传播。海波的图是动态演化的，不适合全批量
- ❌ **标签依赖**：海波不假设有任何监督信号。如果混入标签，方法论上就退化了
- ❌ **固定图结构**：GCN 的图是静态的（一次构建后边不变），海波的图在每次交互后都会演化

## 六、一个具体的实验想法

### 实验：GCN 式邻居聚合能否提升围合计数？

**问题**：海波的围合（enclosure）策略目前通过统计节点周围"概念包围"的模式来做语义消歧。能否借用 GCN 的归一化邻接矩阵 + 层式传播来**重算围合得分**？

**方法**：
1. 构建海波语义图的一个子图（目前数据集：`p0_b2_llm_contexts.json` 的 2100 句语境句）
2. 将 HowNet 义原节点和词节点建图（概念节点 = HowNet sememe，边 = 共现/义原归属）
3. 用 GCN 的重整化邻接矩阵 ˆA 替换海波当前的简单度归一化
4. 堆叠 2 层聚合（对应海波的 2 跳围合）
5. **注意：不做反向传播训练** —— 只用 ˆA 做一次前向特征提取
6. 用提取的"围合特征"加上现有方法做消歧，比较：

| 条件 | 归一化方法 | 层数 | 预期消歧准确率 |
|------|-----------|:----:|:--------------:|
| 基线 | 原始度归一化 | 1 | 当前 ~50% |
| GCN-1 | ˆA 重整化 | 1 | 可能略高 |
| GCN-2 | ˆA 重整化 | 2 | 可能更高（捕获邻域结构） |

**关键约束**：这仍然是一个无监督实验——ˆA 只用于特征提取，不做梯度更新。如果这个方向有效，说明**图结构的规范化预处理本身就是一种强大的先验滤波器**。

**成功标准**：GCN-2 相比基线在消歧任务上提升 ≥5 个百分点。

**关联实验**：[[P0 Series Experiments#P0-R 系列（评测修复）]] 中 P0-R3 的 120 句新语料可以用作评测集。

## 七、批判性评价

### 优点
1. **极致的简化工程** — 从谱图卷积到一阶近似到单参数重整化，每一步都有清晰的理论动机和工程收益
2. **可复现性极高** — 代码开源（60 行核心实现），数据集公开，实验结果完全可复现
3. **开创了 MPNN 范式** — 把"消息传递"从直觉提升为可扩展的算法框架
4. **理论与实践的结合** — WL 同构解释使 GCN 不仅有工程性能，还有理论根基

### 弱点
1. **全批量训练不可扩展** — 大图（如社交网络）无法放入 GPU 内存（后续 GraphSAGE 用采样解决）
2. **层数受限** —— 超过 7 层后性能急剧下降（过度平滑问题），即使添加残差连接也仅缓解
3. **端到端半监督仍然需要标签** — 不是真正意义上的无监督学习。如果标签极少（< 每类 1 个），性能陡降
4. **图结构假设** — 假设图是静态的、无向的。动态图、有向边、边特征都需要额外处理
5. **黑箱权重** — 训练后的 W 矩阵不可解释。你在解释 GCN 时实际上在解释邻接矩阵的谱属性，而不是神经元学到的概念
6. **等权重假设** — 所有邻居权重相同（去掉自适应的能力，GAT 后来解决了这个问题）

## 附录A：方法论决策卡片

> 用于 Haibo 项目决策：论文中的方法可以直接用、改后用、还是纯粹不相关？

### A1 问题映射

| GCN 的问题 | → | 海波的对应问题 |
|-----------|:-:|--------------|
| 图上节点分类（半监督） | → | Semantics Graph 语义消歧（无监督） |
| 邻居特征聚合 | → | 围合（enclosure）概念计数 |
| 同一图结构，少数节点有标签 | → | 同一概念图，上下文激活做消歧 |
| 输出节点分类概率 | → | 输出各义项激活得分 |

**判定**：问题结构同构 ✅ — GCN 解的数学形式可以直接复用。

---

### A2 算法对齐

| 步骤 | GCN 公式 | 海波当前做法 |
|------|----------|-------------|
| 消息构造 | `m_j = h_j^(l) · W^(l)` | `m_j = activation(node_j)` |
| 邻居聚合 | `h_i^(l+1) = σ(Σ Ã_ij · m_j)` | `score_i = Σ w_ij · activation(node_j)` |
| 归一化 | `Ã = D̃^(-1/2) Ã D̃^(-1/2)` | `w_ij = 1/deg(i)`（简单度归一化） |
| 自连接 | `Ã = A + I_N`（重整化技巧） | 无自环 |
| 非线性 | ReLU | 无（当前是线性计数） |
| 多层 | `L 层堆叠 → L 跳感受野` | 单层 |

**判定**：底层操作完全同构 ✅ — 差异仅在归一化方式和层数。

---

### A3 差异分析

| 维度 | GCN | 海波 |
|------|-----|------|
| **训练目标** | 监督：最小化标签交叉熵 | 无监督：无训练目标 |
| **参数更新** | 全局梯度下降 + 反向传播 | 局部赫布式（活动相关） |
| **权重意义** | 学习到的滤波器，黑箱 | 概念间关联强度，可解释 |
| **图结构** | 静态：一次构建后固定 | 动态：每次交互后可能演化 |
| **训练数据** | 需要标注节点 | 完全不需要 |
| **推理方式** | 全图前向传播 | 局部子图激活扩散 |
| **可扩展性** | O(·E·)（全图，不能批处理） | O(·V_local·)（局部子图） |

**判定**：差异在训练机制而非前向传播 ✅。

---

### A4 改造方案

#### 方案 A：直接采用 ˆA 归一化（低风险，3 小时）

把海波当前的简单度归一化 `w_ij = 1/deg(i)` 替换为 GCN 的重整化归一化 `Ã = D̃^(-1/2) Ã D̃^(-1/2)`。

```
当前：  score_i = Σ_j (1/deg(i)) · activation_j
改造：  score_i = Σ_j (1/√(deg(i)+1) · 1/√(deg(j)+1)) · activation_j
```

**优点**：改一行代码，可消除度大的节点主导激活的问题。
**风险**：对海波的小图（<100 节点）影响可能不大。

#### 方案 B：多层传播（中等风险，1 天）

在改造 A 基础上堆叠 2 层激活传播。

```
层1： h_i^(1) = Σ Ã_ij · x_j        （x = 初始激活）
层2： h_i^(2) = Σ Ã_ij · σ(h_j^(1))  （σ = ReLU 或恒等映射）
```

**优点**：2 跳围合可捕获邻域结构（如"苹果公司"和"苹果水果"的邻居模式不同）。
**风险**：多一层 = 多一层噪声，图结构差时退化。

#### 方案 C：随机权重的无监督 GCN（高风险，3 天）

完全不训练，论文已证明随机权重的 GCN 仍可提取图结构特征。

```
1. 构建海波语义图（HowNet 义原 + 共现边）
2. 随机初始化 W^(1), W^(2)
3. 做 2 层 GCN 前向传播
4. 输出节点特征 → 用于消歧分类
```

**优点**：无标签、无训练，完全符合海波方法论。
**风险**：随机权重不稳定，需多次 seed 取均值。

### A6 一句话决策

> **GCN 的前向传播公式可以改一行就用在海波上（R1），但它的训练机制（反向传播+标签）是海波方法论的对立面，绝不能混进来。**
