## 一、Frame Semantics 与 FrameNet

| 标题 | 作者 | 年 | 贡献 |
|------|------|:--:|------|
| *Frame Semantics* | Fillmore | 1982 | 提出框架语义学理论，意义即场景+角色 |
| *The FrameNet Project* | Baker, Fillmore, Lowe | 1998 | 构建 FrameNet 标注体系 |
| *FrameNet: A Knowledge Base for NLP* | Ruppenhofer 等 | 2016 | 系统总结 FrameNet 结构与应用 |
| *Chinese FrameNet* | 刘海波 等 | 2010 | 汉语框架语义标注 |
| *FrameNet 2.0* | Baker, Ellsworth | 2009 | 大幅扩展框架覆盖 |
| *Frame Semantics in the Age of LLMs* | 多位 | 2023-25 | FrameNet + 预训练语言模型结合 |

**与海波的关系**：Semantics Graph v0 的设计思路 = 框架语义学的计算版本——输入词序列激活概念框架。

## 二、HowNet 义原体系

| 标题 | 作者 | 年 | 贡献 |
|------|------|:--:|------|
| *HowNet: A Hybrid Language Knowledge Base* | 董振东, 董强 | 2003 | 提出 HowNet 义原体系 |
| *HowNet: Chinese-English Mixed KB* | 董振东, 董强 | 2000 | 最早公开 HowNet 设计 |
| *Sememe Knowledge Representation in HowNet* | 董振东, 董强 | 2006 | 义原定义与分类体系 |
| *HowNet-Based Chinese WSD* | 刘海波 等 | 2012 | 用义原做中文 WSD |
| *A Survey on Sememe-Based NLU* | 杨一帆, 孙栩, 刘知远 | 2020 | 义原理解综述 |
| *OpenHowNet* | 杨一帆, 刘知远 等 | 2020 | 开放 HowNet 子集和 API |

**与海波的关系**：HowNet 义原可以作为 Semantics Graph 的初始概念节点来源，P0-B 方向直接依赖。

## 三、WSD 基准与关键方法

### 经典基准
- **Senseval / SemEval** — 最权威 WSD 评测系列（1998 起）
- **SemCor** — 基于 WordNet 的全义标注语料
- **OMSTI** — 百万级自动标注语料

### 关键方法

| 标题 | 作者 | 年 | 贡献 |
|------|------|:--:|------|
| *WSD: Algorithms and Applications* | Agirre, Edmonds | 2006 | WSD 方法系统论述 |
| *Knowledge-Free WSD Using WordNet* | Pedersen 等 | 2004 | 词义定义向量相似度消歧 |
| *Improving WSD with Domain Information* | Navigli | 2007 | 引入领域信息 |
| *Neural WSD Using WordNet* | Xue 等 | 2018 | CNN + WordNet 监督 WSD |
| *GlossBERT* | Huang 等 | 2019 | BERT + 词义定义匹配，当时 SOTA。详见 [[GlossBERT论文中文详读]] |
| *Unified Evaluation Framework for WSD* | Raganato 等 | 2017 | 统一评估框架 UFSAC |
| *SenseBERT* | Levine 等 | 2020 | 预训练注入义项信息 |
| *Large-Scale WSD with BERT* | Scott 等 | 2021 | 在 SemEval 刷新 SOTA |

**与海波的关系**：WSD 是"围合消歧"的学科对标。GlossBERT 路线（gloss 匹配）跟海波的"概念激活计数"在直觉上有亲和性。
