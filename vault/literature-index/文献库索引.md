### 与 Haibo 假设链的关系

```
H-SG-1 语义分区     ← 计算语言学(WSD) + NLP(表示空间)
H-SG-2 节点固化     ← 认知语言学(原型) + 知识表示(语义网络)
H-SG-3 关系形成     ← 知识表示(知识图谱嵌入) + 计算语言学(FrameNet)
H-SG-4 持久状态     ← 知识表示(图学习)
H-SG-5 下游价值     ← NLP(LLM 接口)
```

### 方法论卡片模板

以后每读一篇方法类论文，按这个套路做：

```
A1 问题映射    → 论文解决什么问题 → 海波有没有同样的问题
A2 算法对齐    → 论文的公式 → 海波的公式，逐行比
A3 差异分析    → 训练方式、图结构、要不要标签，列清楚
A4 改造方案    → 3种选一：直接抄过来用 / 改了再用 / 只借鉴思路
A5 决策建议    → 最优先先做 / 先跑个实验看看 / 以后再说 / 不用
A6 一句话决策   → 能抄什么、不能抄什么
```
