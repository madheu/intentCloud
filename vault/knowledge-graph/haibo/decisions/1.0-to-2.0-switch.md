# 1.0 → 2.0 方向切换

> 2026-07-18 审查委员会决定

---

## 背景

1.0 路线：手编 36 节点语义图 → Embedding 注入 → LLM 生成方向控制

## 关闭原因

| 问题 | 证据 |
|:----|:-----|
| embedding 注入无法控制 LLM | 类间/类内比 0.93 和 0.99 |
| 赫布学习 + 扩散不可共存 | 3 节点全连通图发散，ρ(A)=1.099 |

## 2.0 新方向

核心问题：**区分歧义的最小维度是什么？**

不再做 embedding 注入控制 LLM，而是先建立语义图消歧基础。
