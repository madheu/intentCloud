# 激活扩散改造清单：Semantics Graph v0

> 汇总 9 篇论文的方法论决策，形成海波语义图激活扩散的完整改造方案。
> 最后更新：2026-07-22

---

## 一、当前状态（改什么）

海波目前的围合计数：

```
score(义项) = Σ_j w_ij · activation(node_j)
w_ij = 1/deg(i)
```

| 维度 | 当前做法 | 问题 |
|------|---------|------|
| 邻居权重 | 等权 `1/deg(i)` | 度大的节点主导激活 |
| 传播层数 | 单层（1跳） | 只捕获直接邻居，错过2跳语义 |
| 轮次 | 单轮 | 无法细化邻域结构 |
| 边类型 | 无（所有边等权重） | 上下位/属性/因果混为一谈 |
| 邻居选择 | 全邻居 | 大规模图时不可控 |
| 自身vs邻居 | 混在一起 | 自身义项得分与邻居贡献不分 |
| 节点特征 | 无 | 语义消歧依赖纯拓扑 |

## 二、改造方案（改成什么样）

### R1：重整化归一化替换简单度归一化

**来源**：[GCN论文中文详读 → R1](http://localhost:0)  
**工期**：3 小时 | **风险**：低

```
当前：    w_ij = 1/deg(i)
改造后：  w_ij = 1/√(deg(i)+1) · 1/√(deg(j)+1)
         Ã = A + I（加自环）
```

改一行归一化公式。对称归一化同时考虑出发节点和目标节点的度，避免大度节点吃掉激活。

---

### R2：Message-Update 职责分离

**来源**：[MPNN论文中文详读 → R1](http://localhost:0)  
**工期**：4 小时 | **风险**：低

```
当前：  score_i = Σ_j w_ij · x_j            （消息和更新混在一起）
改造后：m_i = Σ_j w_ij · M(x_j, x_i)          （Message 阶段：构造消息）
        h_i = U(x_i, m_i)                     （Update 阶段：更新状态）
```

把"从邻居收信号"和"用收到的信号更新自己"拆成两个显式步骤，为后续加边类型、多层传播做准备。

---

### R3：自身+邻居拼接归一化

**来源**：[GraphSAGE论文中文详读 → R2](http://localhost:0)  
**工期**：30 分钟 | **风险**：低

```
当前：  score_i = Σ w_ij · x_j                （自己和邻居混一起）
改造后：h_i = σ( W_self · x_i ∥ W_neigh · m_i )  （拼接自身+邻居聚合结果）
简化版：score_i = α · x_i + (1-α) · Σ w_ij · x_j  （加权自身+邻居）
```

可解释版本：引入超参 α 控制"自身义项证据"和"邻居语义环境"的相对权重。

---

### R4：固定 K 邻居采样

**来源**：[GraphSAGE论文中文详读 → R1](http://localhost:0)  
**工期**：2 小时 | **风险**：低

```
当前：  使用所有邻居 → 度大的节点贡献不成比例
改造后：对每个节点固定采样 K 个邻居 → 激活聚合的邻居数一致
```

在海波的小图（<100 节点）上影响不大，但为后续图扩展做好准备。

---

### R5：边类型系数传播

**来源**：[TransE论文中文详读 → R1](http://localhost:0)  
**工期**：4 小时 | **风险**：中

```
当前：  score_i = Σ w_ij · x_j              （所有边等权重）
改造后：score_i = Σ α(r_type) · w_ij · x_j   （每类关系一个传播系数）
```

从 HowNet 的 7 种关系类型派生 α(r)：
| 关系类型 | α | 含义 |
|---------|:-:|------|
| 上下位（hyponym） | 1.0 | 强传播，上下位直接决定语义 |
| 属性（attribute） | 0.7 | 中等，属性提供语境约束 |
| 因果（causal） | 0.5 | 中等偏弱，因果可逆 |
| 共现（cooccurrence） | 0.3 | 弱传播，共现提供统计信号 |

---

### R6：多头围合（多视角并行）

**来源**：[GAT论文中文详读 → R1](http://localhost:0)  
**工期**：4 小时 | **风险**：低

```
当前：  单视角围合 → 所有义项共享同一套邻居重要性
改造后：多视角并行 → 3-4 个头并行查围合，每个头关注不同概念子空间
```

```
头1：关注上下位邻居  → 捕捉范畴归属
头2：关注属性邻居    → 捕捉特征约束
头3：关注共现邻居    → 捕捉统计信号
```

各头得分做均值/拼接 → 最终义项得分。

---

### R7：多轮围合（h=3）

**来源**：[WL图同构中文详读 → R1](http://localhost:0)  
**工期**：1 天 | **风险**：中

```
当前：  单轮围合 → 只看到直接邻居（1跳）
改造后：h=3 轮迭代 → 看到 1跳→2跳→3跳 邻域结构
```

```
轮1：  h_i^(1) = aggregate(1跳邻居)
轮2：  h_i^(2) = aggregate(1跳邻居的 h^(1))   ← 捕获2跳结构
轮3：  h_i^(3) = aggregate(1跳邻居的 h^(2))   ← 捕获3跳结构
特征： 拼接 [h^(1), h^(2), h^(3)]           ← 保留所有轮次
```

WL 论文实验证明 h>0 比 h=0 在 NCI1 上提升 +16%。

---

### R8：边类型嵌入参与消息

**来源**：[MPNN论文中文详读 → R2](http://localhost:0)  
**工期**：1 天 | **风险**：中

```
当前：  消息 = 邻居激活值 × 权重
改造后：消息 = 邻居激活值 × 权重 × 边类型向量
```

当 R1-R7 稳定后，把边类型从标量系数 α(r) 升级为向量，使不同类型的关系不仅影响传播强度，还影响传播的内容。

## 三、实施顺序

### 阶段一：核心改造（〜3 天）

| 顺序 | 改造 | 工期 | 依赖 | 完成后验证 |
|:----:|------|:----:|:----:|-----------|
| 1 | R1 重整化归一化 | 3h | — | 小图上围合计数不崩溃 |
| 2 | R3 自身+邻居拼接 | 30min | — | 验证 α 不同取值的影响 |
| 3 | R2 Message-Update分离 | 4h | R1 | 前向传播结构清晰 |
| 4 | R6 多头围合 | 4h | R2, R3 | 多视角 vs 单视角对比 |

### 阶段二：增强改造（〜3 天）

| 顺序 | 改造 | 工期 | 依赖 | 完成后验证 |
|:----:|------|:----:|:----:|-----------|
| 5 | R5 边类型系数 | 4h | R2 | 有类型 vs 无类型传播对比 |
| 6 | R4 固定K采样 | 2h | — | 全图 vs 采样对比 |
| 7 | R7 多轮围合h=3 | 1d | R2, R1 | h=1 vs h=2 vs h=3 对比 |

### 阶段三：深度改造（〜1 天）

| 顺序 | 改造 | 工期 | 依赖 | 完成后验证 |
|:----:|------|:----:|:----:|-----------|
| 8 | R8 边类型嵌入 | 1d | R5, R7 | 标量系数 vs 向量嵌入 |

### 绝对不做的

```
❌ 反向传播训练           — 违反海波核心方法论
❌ 标签依赖               — 无监督是根本立场
❌ 全批量训练              — 图需动态演化
❌ 可训练注意力参数        — 赫布式学习的对立面
❌ 单语义空间嵌入          — 多义词需要上下文激活
```
