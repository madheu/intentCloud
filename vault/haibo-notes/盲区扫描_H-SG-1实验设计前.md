# 盲区扫描：Semantics Graph v0 还有什么没想清楚的

> 基于审查结论，查找在"动手之前"需要先回答的问题。
> 2026-07-22

---

## 盲区 1：海波没有 BriLLM，怎么做 Token 活动模式？

H-SG-1 的原文：
> "不同语义上下文的 **Token 活动模式** 可以无监督形成稳定分区"

但海波没有 BriLLM，也没有任何 Token 底座的实现在代码里。
我们的**实际能力**是概念节点的围合计数，不是 Token 活动向量聚类。

**问题**：H-SG-1 的实验到底用 Token 活动向量（需 BriLLM）还是围合特征向量（海波自己有）？

**回答**：用围合特征向量做。理由：
- BriLLM 的 Token 活动 = 海波的围合计数，数学同构（WL 证明）
- 围合特征不需要 BriLLM，只依赖 HowNet 概念图和上下文词
- 如果围合特征能区分义项，就证明"语义分区的信息存在于概念邻域结构中"
- 这与 H-SG-1 的精神一致，只是实现路径不同

**但需要明确写进假设链：** 当前 H-SG-1 的表述会让人以为需要 BriLLM，需要澄清。

---

## 盲区 2：静态 HowNet 图存不存在足够的结构差异？

WL 图同构证明：如果两个节点的邻域结构不同，迭代聚合后一定可以区分。

**但问题在于**：HowNet 的语义图对于近义词来说可能**结构太相似**。

```
苹果[公司] 的语义图： 苹果 ─公司─企业─上市─产品
苹果[水果] 的语义图： 苹果 ─水果─食物─吃─甜

如果图中的路径是：
公司 ─属性─ 商业
水果 ─属性─ 美味

这两条路径是分开的，差异明显 ✅
但如果 HowNet 中公司和水果都连到"物质"：
苹果 ─公司─物质
苹果 ─水果─物质
← 共享"物质"节点，结构可能部分重合
```

**问题**：HowNet 的义原图拓扑差异够不够大，让不同义项的围合模式可区分？

**答案**：不确定，**这正是 H-SG-1 实验要回答的问题。** 如果实验结果显示围合模式高度重合（PCA 投影后混在一起），那就说明纯图拓扑不够，需要边类型加权或上下文辅助。

## 盲区 3：围合特征怎么从句子中提取？

H-SG-1 实验需要一个明确的特征提取管道：

```
输入句子 → 定位目标词 → 提取上下文词
  → 查 HowNet 获取每个上下文词的义原
  → 统计义原频次 → 得到围合特征向量
  → 聚类
```

**未解决的问题：**
- 上下文窗口多大？（目标词±3？±5？全句？）
- 有多义词上下文词怎么办？（"他_花了钱"中的"花"是动词还是名词？）
- 如果上下文词本身也需要消歧，那围合提取就变成了递归问题

**可行的简化**：第一阶段**所有上下文词用 HowNet 第一义项**（MFS），不做全消歧。这是 P0-R 已验证可行的方法——MFS 基线弱但够用。

## 盲区 4：怎么定义"通过"？实验成功的标准是什么？

H-SG-1 的证伪条件：
> "分区与随机打散的聚类差异不显著"

但这需要量化：

| 指标 | 怎么算 | 通过线 |
|------|--------|--------|
| 聚类纯度 | 每个簇中多数义项的占比 | > 0.7 |
| 调整兰德指数（ARI） | 聚类与真实标签的匹配度 | > 0.3 |
| 轮廓系数 | 簇内紧凑 vs 簇间分离 | > 0.2 |
| **与随机基线对比** | 随机分配义项标签的 ARI | **必须显著高于随机** |

**最关键的是最后一条**——如果海波的方法 ARI=0.35，随机基线 ARI=0.05，那就通过了。
如果 ARI=0.12，随机 ARI=0.05，那信号太弱，假设不成立。

## 盲区 5：实验词选哪些？

P0 系列用过的 6 个歧义词（花/光/行/口/纸/火）加上新词的覆盖：

```
P0 已验证的：6个（有金标）
P0-B LLM语料：230个词 × 多语境（2100句，已有数据）

实验策略：
阶段一：6个P0词 × 各10句 → 快速验证围合特征可区分
阶段二：扩展到20-30个词 × 多语境 → 验证泛化
```

**第一阶段不需要新金标**——P0 的金标可以直接复用。
**第二阶段**需要确保每个词在多个不同语境中出现（已有的 2100 句 LLM 语料应该够用）。
