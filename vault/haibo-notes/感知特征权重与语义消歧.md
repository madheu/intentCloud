# 感知特征在语义消歧中的权重

> 户的直觉："甜、重、香、音质、流畅、质感、气味——这些词你一看就知道是形容什么苹果的，感知词应该占更大权重。"

---

## 一、直觉总结

"甜"→水果苹果，"音质"→科技苹果。感知词比抽象词（"这款"、"比"）有**更强的诊断性**（diagnosticity）。同样的逻辑也适用于反例："重"如果是重量→水果（苹果很重），如果是手感→科技（手机很重）。

---

## 二、理论支撑

### Barsalou (1999) — Perceptual Symbol Systems

**核心主张**：认知不是用抽象符号（amodal symbols）运算的，而是用**知觉符号**（perceptual symbols）——概念在大脑中以感知-运动系统的模拟形式存储。

```
"甜" → 不仅是一个词，而是味觉系统的重激活（舌尖的记忆）
"音质" → 听觉系统的重激活（听到清晰声音的记忆）
"重" → 体感系统的重激活（手沉的感觉）
```

这意味着**感知词直接触发了概念的核心内容**，而不是通过抽象定义间接指向。这解释了为什么感知词的诊断性更强。

**出处**：Barsalou, L. W. (1999). Perceptual symbol systems. *Behavioral and Brain Sciences*, 22(4), 577-609.

**免费PDF**：https://barsaloulab.org/Online_Articles/1999-Barsalou-BBS-perceptual_symbol_systems.pdf

### 核心论点（全文83页，含44页同行评议）

Barsalou 在这篇论文中直接挑战了认知科学的主流教条：**概念不是非模态的抽象符号（amodal symbols），而是知觉符号（perceptual symbols）——即感知-运动系统的神经重激活记录。**

#### 知觉符号的四个核心特征

1. **它们是知觉的神经关联，而不是对知觉的抽象翻译**
   - 看到"红"时激活的是视觉系统处理红色的神经模式，不是某个抽象标签 RED
   - 这意味着感知词（甜、香、重）直接触及概念的核心内容

2. **它们是图解式的（schematic），不是完整的知觉副本**
   - 不是完整的录像回放，而是提取了关键感知维度的选择性重激活
   - 对"苹果"的味觉模拟：只有"甜/酸/脆"等关键维度被存储，不是整个吃苹果的体验

3. **它们是可组合的**
   - 简单的知觉符号可以组合成无限复杂的模拟
   - "甜" + "红" + "圆" → 某种水果的模拟，不需要标签

4. **它们在大脑中是分布式的**
   - 一个概念激活多个感知-运动系统
   - "苹果"同时激活视觉（形状/颜色）、味觉（甜/酸）、触觉（光滑/重）、运动系统（咬的动作）

#### 这篇论文怎么支撑你的直觉

你的直觉"甜、香、重这些感知词应该占更大权重"在 Barsalou 框架下有直接的理论基础：

```
传统观点（Barsalou反对）：
  "甜" → 抽象符号 SWEET → 跟其他抽象符号等权运算

Barsalou 观点：
  "甜" → 味觉系统的部分重激活 → 携带感知-运动信息 → 在概念网络中
         具有"接地"特权（grounded privilege）
```

**接地特权**（grounded privilege）：直接源自感知经验的词，比间接通过定义习得的词，有更强的概念绑定。因为它们的神经激活路径更短、更直接。

#### 对 Haibo 的直接意义

1. **感知词权重有神经科学依据** — 不是设计选择，是认知架构的特征
2. **区分"接地词"和"空中词"** — "甜"是接地词（直接感知），"设计"是半抽象词（部分接地），"比"是纯抽象词（不接地）
3. **接地强度可以作为概念激活权重的先验** — 接地越强，诊断性越高

#### 论文的反驳与回应

这篇论文发表了之后附带了 **44 页同行评议**（33 位学者评论 + Barsalou 回复），这是 BBS 期刊的特色。主要的反驳包括：
- 知觉符号能否表示抽象概念（如"正义""民主"）？
- 知觉符号的存储格式问题
- 是否需要非模态符号作为补充

Barsalou 的回应策略是：抽象概念通过**情境模拟**（situated simulation）实现——"正义"激活的是体验过正义情境的感知-运动系统。这个观点后来发展成了"情境概念化理论"（Situated Conceptualization）。

### Harnad (1990) — Symbol Grounding Problem

**核心主张**：符号的意义必须最终锚定在感知-运动经验上，否则只是"符号-符号"的无限循环（字典循环）。

```
查表归属：   "甜"→水果类（这只是符号到符号的映射）
接地归属：   "甜"→味觉经验（这才是意义）
```

如果 Haibo 的 word→concept 归属表能区分"感知接地词"和"抽象词"，就能在权重上反映这种差异。

**出处**：Harnad, S. (1990). The symbol grounding problem. *Physica D*, 42(1-3), 335-346.

### 特征规范理论（Feature Norms）

McRae 等人的语义特征生产实验发现：**感知特征（形状、颜色、味道、质地）比功能特征在概念区分中更重要**。

```
"苹果"（水果）的核心特征：甜、脆、红/绿、圆 → 大部分是感知的
"苹果"（科技）的核心特征：创新、贵、生态、设计 → 大部分是功能/评价的
```

这意味着：
- 水果类概念偏向**感知特征**密集
- 科技类概念偏向**功能/评价特征**密集
- 因此**感知词**在区分这两类时具有高权重

## 三、对 Haibo 的设计意义

### 3.1 词级权重方案

不是所有词都等权。可以引入**感知诊断性权重**：

```
"甜" → 感知权重: 0.9（高度感知，高度诊断）
"音质" → 感知权重: 0.85（听觉，高度诊断）  
"重" → 感知权重: 0.6（体感，但跨两类时需语境）
"这款" → 感知权重: 0.0（纯指示词，无诊断性）
"比" → 感知权重: 0.0（虚词，无诊断性）
"设计" → 感知权重: 0.3（部分感知-视觉，但也可抽象）
```

概念激活计数 = Σ(词激活 × 词感知权重)

### 3.2 概念级的感知分布

可以把感知维度作为概念的一个属性：

```python
class SemanticConcept:
    name: str  # "科技类", "水果类"
    perceptual_profile: dict  # 感知维度分布
    # {
    #   "taste": 0.1,      # 科技类不太涉及味觉
    #   "touch": 0.3,      # 手感设计
    #   "sound": 0.2,      # 音质
    #   "vision": 0.4,     # 外观设计
    #   "smell": 0.0,      # 不涉及
    # }
```

当输入中有感知词时，匹配概念的感知维度做加权。

### 3.3 与 P0 实验结果的关系

P0.5 发现"词级静态向量空间不足以区分语义歧义"——其中"静态向量"（词向量）的问题之一就是**所有维度等权**，没有区分感知维度和抽象维度。

P0-R 级联 58.3% 的障碍之一是：级联中每一层都是等权投票，没有为高诊断性感知词加权。

## 四、跟 GlossBERT 的对比

GlossBERT 虽然不显式区分感知词，但 BERT 的隐层表示中感知词和抽象词自然有不同的激活模式。语义匹配时，BERT 隐式利用了这种差异。

Haibo 的优势在于可以**显式建模**感知权重——透明、可控、可调试。
