# 理论审查：Semantics Graph v0 当前状态

> 基于 9 篇论文的方法论卡片，审查 Haibo 2.0 的项目假设、代码和实验路线。
> 最后更新：2026-07-22

---

## 一、审查发现

### 发现 1：代码存在阶段断层

IntCog-R 核心代码是 **Haibo 1.0 遗产**（intent_cloud.py, steering.py, embedding 注入等），
Semantics Graph v0 **不存在任何实现代码**。

```
当前代码库：1.0 注入系统（已证伪，已关闭）
实验代码：  P0-B hand-crafted 物/事/质/序映射
缺失：      概念节点图、归一化传播、采样、边类型
```

**严重性**：⚠️ 中等 — 这是正常的（P0 系列本来就是先实验后实现），
但需要注意：**P0-B 的实验脚本也是 1.0 思路的延续，不是 2.0 思路**。

---

### 发现 2：P0-B 实验脚本继承自 P0-A 的错误范式

`p0_b1_hownet.py` 的核心逻辑：
```
HowNet 义原 → 手工映射到 4 面（物/事/质/序）→ 点积消歧
```

这与 9 篇论文的结论存在 **3 个冲突**：

| 冲突 | P0-B 做法 | 论文告诉我们 |
|------|-----------|-------------|
| 维度 | 手工 4 面压缩 | WL/GCN：用图拓扑而非降维。围合计数保留全部邻居结构 |
| 传播 | 无归一化 | GCN：`Ã = D̃^{-1/2}ÃD̃^{-1/2}` 是保证稳定的最小前提 |
| 边类型 | 无 | TransE/MPNN：边类型是语义图的定义特征 |

**严重性**：🔴 **高** — P0-B 的实验管道如果继续走 4 面映射路线，
产出的数字可能对 Semantics Graph 设计没有参考价值。

**建议**：P0-B 实验不应直接废弃，但应**降级为"义原覆盖分析"**
（验证 HowNet 对实验词的义原覆盖够不够），不作为消歧方案原型。

---

### 发现 3：假设链 H-SG-1~5 需要补充传播机制

当前假设链写于 2026-07-21（论文阅读之前），
描述了**做什么**但没有描述**怎么做**：

```
H-SG-1：语义分区             ← 存在，但没说分区算法
H-SG-2：节点固化             ← 存在，但没说固化机制
H-SG-3：关系形成             ← 存在，但没说关系提取方式
H-SG-4：持久状态             ← 存在，但没说更新策略
H-SG-5：下游价值             ← 存在，但没说接口方式
```

论文阅读后的补充（建议追加到假设文档的"技术约束"部分）：

```
技术约束 A：传播机制
- 前向传播 = MPNN 的 Message→Update 框架（已对齐）
- 归一化 = GCN 重整化对称归一化（R1）
- 边类型 = TransE 关系系数 + HowNet 7 种关系（R5）

技术约束 B：围合算法
- 围合 = WL 多轮迭代 h=3（R7）
- 多头 = GAT 多视角并行 3-4 头（R6）
- 邻居选择 = GraphSAGE 固定 K 采样（R4）

技术约束 C：不采用
- 不反向传播、不标签依赖、不训练注意力参数
- 不手工压缩维度（4 面映射已废弃）
```

**严重性**：⚠️ 低 — 假设链本身没错，只是缺少实现约束。

---

### 发现 4：激活扩散存在形式化缺口

从 Control Scientist 视角，当前激活扩散缺少：

| 问题 | 体现 | 论文解法 |
|------|------|---------|
| 收敛性 | 1.0 时代谱半径>1 发散 | GCN 重整化归一化保证谱半径 ≤ 1 |
| 方向性 | 所有边等权重 | TransE 关系类型系数 |
| 深度控制 | 固定单层 | MPNN T 步 + WL 多轮 |
| 稳定性 | 无自环 | GCN 自连接 `Ã = A + I` |

**严重性**：⚠️ 中 — 1.0 时代发现过发散问题（恐惧路径失控），
2.0 如果照抄 1.0 的激活扩散逻辑而不加重整化，同样的问题会复现。

---

### 发现 5：实验验证链有缺口

```
H-SG-1（语义分区） ← 无实验
H-SG-2（节点固化） ← 无实验
H-SG-3（关系形成） ← 无实验
H-SG-4（持久状态） ← 无实验
H-SG-5（下游价值） ← 无实验
```

P0 系列的 14 轮实验验证的是**手工词表消歧**，不是**语义涌现**。
从假设链到实验之间存在 **方法论文献到实验设计的映射缺口**。

**严重性**：🔴 **高** — 项目当前没有实验验证任何一条 H-SG 假设。
改造清单的 P1 决策落地后，应该立即设计针对 H-SG-1 的最小实验。

## 二、审查结论

### 通过项

| 项目 | 状态 |
|------|:----:|
| 理论方向 — 语义图而非向量空间 | ✅ 9 篇论文全部支持 |
| 无监督、无反向传播的方法论立场 | ✅ 与论文发现的非监督方法（WL）一致 |
| 概念节点而非词节点的设计 | ✅ GNN 全用图节点而非文本 Token |
| HowNet 作为初始知识源 | ✅ 已被多篇论文验证（WSD 任务） |
| 围合（enclosure）的核心直觉 | ⭐ WL 图同构证明这是图论标准解法 |

### 不通过项

| 项目 | 问题 | 建议 |
|------|------|------|
| P0-B 4 面映射实验 | 继承自 P0-A 的废弃路线 | 降级为义原覆盖分析 |
| 假设链缺少实现约束 | 只描述做什么 | 追加技术约束 A/B/C |
| 无 Semantics Graph 代码 | 代码库仍是 1.0 遗产 | 阶段一改造完成后写 v0 |
| 无 H-SG 验证实验 | 14 轮 P0 验证的是消歧不是涌现 | P1 落地后设计最小实验 |

### 风险评级

```
实施风险：中 — 改造方案清晰，但代码重写量大
理论风险：低 — 9 篇论文一致支持当前方向
实验风险：高 — H-SG-1~5 没有任何实验验证
```

---

## 三、建议的下一步

### 优先做（停止损失）

1. **P0-B 实验脚本降级** — 不再用它产出消歧正确率，改做义原覆盖分析
2. **假设链补充技术约束** — 追加传播机制、围合算法、不采用清单

### 然后做（打好基础）

3. **写激活扩散 v0 的最小实现** — 只做 Message→Update 框架 + 重整化归一化（R1+R2，~7h）
4. **在最小图上验证** — 用 HowNet 3-5 个概念节点构建小图，验证传播不崩溃

### 再做（验证假设）

5. **H-SG-1 最小实验** — 给定同一 Token 在不同上下文中的围合模式，聚类验证与随机基线差异显著
6. **H-SG-2 最小实验** — 验证同一义项跨句能稳定激活同一组概念节点
