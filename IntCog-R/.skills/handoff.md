# handoff

> 来源：mattpocock/skills — 对话压缩为交接文档
> 适配：IntCog-R 项目，用于跨 agent 上下文传递

## 触发条件

用户说"导出进度"、"交接"、"给本地 agent 同步"、"写一个 handoff"。

## 执行格式

生成一个结构化交接文档，包含：

```markdown
# 交接文档 — [日期]

## 当前状态
- 分支 / 最新 commit
- 测试通过数
- 未提交变更

## 已完成
- 模块名 → 文件 → 一行总结

## 待办
- P0: ...
- P1: ...
- P2: ...

## 关键决策
- 决策 → 原因

## 下一步
- 建议的下一步操作
- 建议调用的 skill

## 已知问题
- 问题 → 状态
```

## 规则

- **不重复已有内容**：已写入 spec/plan/commit 的内容用路径或 URL 引用
- **不包含敏感信息**：API key、密码、token 等
- **保存位置**：`/workspace/IntCog-R/` 目录下
