# Intent Cloud v0.1 对话实跑分析报告

## 数据来源

24 轮人机对话，运行 `frontal_lobe_prototype.py`，模型 qwythos:latest。

## 一、意图提取质量

**好的方面**：约 70% 轮次的 core_task/deep_goal 准确捕捉用户状态。

**三个系统性问题**：

1. **identity 字段几乎全为"未知"**（23/24 轮）。模型没有从对话中提取用户自述身份。
2. **constraints 常为 `[]`**。用户约束（"不要鸡汤"）被捕获但未结构化进入后续蓝图。
3. **deep_goal 偶有过度推断**（如"你好"→"求认可"），模型在"编故事"而非"建模状态"。

## 二、跨轮次激活模式

| 轮次 | 激活 ID | 分析 |
|------|---------|------|
| #1 | 001 | 首轮，仅自身 |
| #2 | 002, 001 | 当前 + 首轮 |
| #4 | 004, 001, 003 | ID#001 幽灵出现 |
| #24 | 024, 019, 001 | ID#001 仍在 |

**ID#001 共被激活 10 次**（阈值 0.02 过低 + n-gram 碎片碰撞），成为持久噪音。

## 三、蓝图控制力

**蓝图生效的轮次**：
- #2 角色覆盖：identity="太一" → 模型以"我是太一"回答
- #6 矛盾指令：constraints 含"不要建议" → 模型只复述
- #10 风格切换：constraints 含"理性解释" → 回答变简洁

**蓝图失效的轮次**：
- 模型固有身份"我是 Qwythos"贯穿始终
- constraints 不跨轮：#6 说"不要建议"，#7 仍给建议

## 五、与 ChatGPT 评估的对照

| ChatGPT 判断 | 验证结果 |
|-------------|---------|
| "解释结构"≠"真实状态" | 验证：identity 字段几乎为空 |
| 没有对照实验 | 验证：确实无 baseline |
| 状态是规则生成的 | 验证：全靠 LLM 一次推断 |
| 架构方向对（Cognitive Wrapper） | 验证：蓝图在关键轮次确实生效 |
