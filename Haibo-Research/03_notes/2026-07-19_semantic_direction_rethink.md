# 研究笔记 2026-07-19：语义方向问题的重新定位

> 记录性质，非结论。今天和 ChatGPT 讨论后梳理的思考线索。

---

## 一、当前卡在哪

P0-A-5 的布尔 4 轴（天/地/人/心）跑出了 50% 的正确率，纸 83%、光 50% 有提升，但苹果从 82% 掉到 45%。

当时的问题是：**4 个轴够不够？轴的定义对不对？要不要找到更精确的轴？**

今天讨论后认为：这个方向本身可能有问题——**我们可能在尝试重新发明语义分类学，而这不是海波应该做的事。**

---

## 二、讨论中浮现的一个区分

海波要做的事和语言学要做的事是两件不同的事：

| 语言学的事 | 海波的事 |
|-----------|---------|
| 定义词义的基本单位是什么 | 如何用图动态组织这些单位 |
| 找到语义分类体系 | 如何计算、学习、演化语义结构 |
| 确认"施事""受事"等角色的定义 | 怎么把语义角色作为图边的类型来用 |

问题在于 P0-A 系列一直隐含了一个假设：**"找到一组万能语义方向"是海波的前提。** 但讨论后认为可能不是——更好的路线是：**已有语言学理论的成果直接拿来用，海波的创新放在如何计算上。**

---

## 三、讨论中提到的几条可用理论

### 1. Frame Semantics（框架语义学, Fillmore）

一个词激活一个完整的语义框架，而不是一个孤立的概念。

```
"购买" → 框架包含：买方、卖方、商品、价格、交易、目的
```

和 P0.10 中"概念域"的思路很接近——"苹果"在不同框架下（科技公司框架、水果框架）指向不同方向。可以理解为：**围合就是激活框架的过程。**

### 2. Semantic Role（语义角色）

NLP 里已经成熟：Agent、Patient、Instrument、Time、Location、Cause、Purpose、Manner。

这些可以直接作为图的边类型候选，不用重新设计。

### 3. Ontology（上层本体）

知识表示的基础分类：Entity、Event、State、Property、Relation、Time、Space。

可以作为概念节点类型参考——比"天/地/人/心"更接近已有文献。

### 4. Prototype Theory（原型理论, Rosch）

类别没有严格边界，有中心成员和边缘成员。

与图扩散一致：一个词义的激活更像一个"激活区域"（在图上扩散后的分布），而不是一个固定点。

### 5. Natural Semantic Metalanguage（NSM, Wierzbicka）

尝试找少量语义原语。目前没有形成共识，但可以作为参考——**海波如果要用语义原语，应该从 NSM 出发，而不是自己发明一套。**

## 四、讨论中出现的一个新假设

> **海波的创新点可能不是重新定义 Semantic Direction，而是提出一种"动态图组织 Meaning"的计算框架。**

即：
- 节点、边、语义角色等基础元素继承已有理论
- 海波负责研究这些元素如何通过激活、扩散、学习和重构形成动态意义

如果这个假设成立，海波的理论贡献在**计算架构**层面，不在**语言学基础理论**层面。

这会影响：
- P0-A 后续的实验目标（验证什么？）
- 文献调研方向（读什么？）
- 项目定位（怎么对外描述？）

## 五、关于 Semantic Vector 的定位

讨论中也提到 Semantic Vector（SV）的定位问题：

当前设想：SV 不是取代语义图，而是图中的一种**计算节点**——负责生成当前语义状态的连续表示（mean）。

```
输入 → 语义图激活 → Semantic Mean（SV）→ 提供连续状态表示
```

图承担：关系表示、推理、可解释性、结构学习。
SV 承担：图的连续摘要。

这个定位还没有验证，记下来留后续讨论。
