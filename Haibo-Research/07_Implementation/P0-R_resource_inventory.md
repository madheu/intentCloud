## 一、中文语义资源

### 1. HowNet（知网）— ✅ **已获取，建议作为主要知识源**
- **类型**：义原（sememe）体系 + 词义标注
- **规模**：2000+ 义原，20 万中文词
- **获取方式**：`pip install OpenHowNet` 或 hownet.dat 文件
- **在 P0-R 中的角色**：候选义项集、义原相似度计算、图节点来源
- **已跑通**：P0-B-1 确认 6 个歧义词和关键语境词都有准确义项标注
- **咨询师的建议**：不要压缩成 4 轴，直接做义原图重叠

### 2. 腾讯中文词向量（Tencent 200d）— ✅ **已获取，仅作弱证据**
- **类型**：200 维静态词向量
- **规模**：14 万词 × 200 维
- **文件**：`E:\intentCloud\models\text2vec-word2vec-tencent-chinese\light_Tencent_AILab_ChineseEmbedding.bin`
- **在 P0-R 中的角色**：可选弱证据（余弦相似度作为备选信号）
- **使用方式**：`from gensim.models import KeyedVectors`
- **咨询师的建议**：不加在 v1 中，v2 才考虑作为 auxiliary edge

### 3. 同义词词林（扩展版）— ⚠️ **需下载，推荐加入**
- **类型**：5 层语义分类树（大类 → 中类 → 小类 → 词群 → 原子词）
- **规模**：约 7 万词
- **特点**：每层 3-5 个分支 —— 和我们"每次只比 4 个维度，超出就拓层"天然一致
- **下载**：哈工大社会计算与信息检索研究中心
- **在 P0-R 中的角色**：备选语义面层级结构。如果 HowNet 义原图不理想，可替换为词林的 5 层树

### 4. OpenHowNet Python 包 — ✅ **已有 pip 包**
- `pip install OpenHowNet` 可直接使用
- 提供了 `get_senses(word)`、`get_sememes(sense)` 等 API
- 避免手动解析 hownet.dat

### 5. Chinese WordNet — ⚠️ **需下载，不优先**
- 中文同义集 + 上下位关系
- 规模较小（约 1 万词），覆盖不如 HowNet
- 备选，但建议先跑 HowNet

### 6. ConceptNet（中文部分）— ⚠️ **需下载，不优先**
- 多语言常识知识图谱
- 边带有标签（IsA、PartOf、UsedFor、CapableOf 等）
- 中文节点约 10 万，但关系较泛，不专门做消歧
- 备选，如果需要带标签的边类型时再考虑
