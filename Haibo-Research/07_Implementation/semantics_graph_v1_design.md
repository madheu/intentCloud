# Semantics Graph v1 — 分层围合消歧设计

## 2026-07-19 | 已通过 P0.9 + P0.10 验证

---

## 一、核心思想

**语义不是用向量空间算出来的，是用词→概念的归属关系"围"出来的。**

```
输入词集 → 查表（每个词属于哪些概念）→ 概念激活计数 → 分层比对 → 输出
```

**分层依据**：不在 6+ 个概念中做一次比较。每次只比 2-4 个，平局才展开。

---

## 二、图结构

### 2.1 概念分层

```
Layer 0（根）: 语义世界
  ├── Layer 1（大类）: 科技, 水果, 人物, 情感, 动作, 自然, ...
  │   ├── Layer 2（子类）: 科技_消费电子, 科技_产品, 科技_研发, ...
  │   ├── Layer 2（子类）: 水果_种植, 水果_品质, 水果_品种, ...
  │   └── ...
  └── 中性词（不属于任何类）
```

### 2.2 节点类型

| 节点类型 | 例子 | 作用 |
|---------|------|------|
| **词节点**（最底层） | "手机"、"甜"、"树" | 输入信号入口 |
| **概念节点**（中间层） | "科技_消费电子"、"水果_品质" | 接收词节点的激活，汇聚成概念激活 |
| **大类节点**（顶层） | "科技"、"水果" | 接收子概念激活，做第一层判断 |
| **中性词节点** | "比"、"这款" | 挂在大类之外，不产生激活 |

### 2.3 边类型

| 边 | 方向 | 含义 | 权重 |
|----|:----:|------|:----:|
| 词 → 概念 | 词→概念 | "这个词属于这个概念" | 1（二值，v1） |
| 概念 → 大类 | 概念→大类 | "这个子类属于哪个大类" | 1（二值，v1） |
| 歧义词 → 大类 | 歧义词→大类 | "这个歧义词可能指向哪个大类" | 1（二值，v1） |

## 三、推理流程

### 分层推理算法

```
输入句子 S

Step 1: 分词 → 词集 W = {w₁, w₂, ..., wₙ}
  过滤中性词（"比"、"这款"等不激活任何概念）

Step 2: Layer 1 — 大类激活
  对每个词 w ∈ W:
    if w ∈ 中性词: continue
    if w ∈ 歧义词: 每个候选大类 +1
    if w ∈ 普通词: 找到它所属的概念 → 找到概念所属的大类 → 大类 +1

  比较各大类的激活值
  if 最高大类 >= 第二高 × 1.5: → 输出结果 ✅
  else: → 展开到 Layer 2

Step 3: Layer 2 — 子概念激活（仅在平局的大类间展开）
  只计算平局大类下的子概念
  对每个词 w ∈ W:
    if w ∈ 中性词: continue  
    if w ∈ 歧义词: 每个平局大类下的所有子概念 +1
    if w ∈ 普通词: 找到它所属的子概念 → 子概念 +1

  比较各子概念的激活值
  if 最高子概念 >= 第二高 × 1.5: → 输出结果 ✅
  else: → "不确定"

Step 4（未来）: Layer N — 如果仍有平局，继续向底层展开
```

### 关键参数

| 参数 | v1 值 | 说明 |
|:----|:-----:|------|
| 比较阈值 | 1.5 | 最高分必须比第二高多 50% 才做判断 |
| 最大展开层数 | 2 | 目前只展开到子概念层 |
| 歧义词自激活 | 1 | 歧义词本身给每个候选大类 +1 |

## 四、范围说明

### 4.1 能做什么（已验证）

- **歧义消解**：一句话中有歧义词时，用上下文词确定其语义方向
- **分层决策**：9/11 测试句在第一层（2 维）直接解决，只有边界情况需要展开
- **全激活输出**：可输出全部概念激活值，不只是最终标签

### 4.2 不能做什么（已知限制）

- **短语级语义**：如"比上一代更甜"中的"上一代"单独指向科技，但整体指向水果。当前无法处理跨词组的语义
- **从未见过的词**：不在词→概念表中的词无法激活任何概念
- **多歧义词共存**：一句话中出现两个歧义词时（如"苹果"和"纸"同时出现），当前未验证
- **大规模**：30-50 概念已验证，300+ 概念未验证

### 4.3 设计原则

1. **每次只做 2-4 维比对**——超出就拓层，不在高维空间里做决策
2. **概念节点是轴，不是向量**——每个概念是一个可解释的语义方向，不是统计成分
3. **词→概念的归属是人对语言的理解，不是从语料中 SVD 出来的**
4. **"不确定"是允许的输出**——不是系统失败，是句子本身模糊
