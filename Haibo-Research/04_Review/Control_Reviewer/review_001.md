## 1/5 核心判断：海波不是一个闭环认知动力系统

系统拓扑：
```
user_input → diffuse_activation (W fixed) → a* → update_weights (a* fixed) → a* → BilingualInjector → LLM
```

这是一个开环前馈链。无反馈 → 无闭环 → 无闭环稳定性可言。

缺失项：
- (a) 状态方程未定义
- (b) LLM 输出 → 下一轮 input_signals 的映射不存在
- (c) 控制律未定义

## 2/5 反直觉的数学事实

### (a) 权重有界性由硬裁剪保证，不是动力学保证

Proj[·,0,1] 掩盖了不稳定的动态。γ=K_d=0 时权重单调增长到 1，失去敏感性。

### (b) η/γ = 10 使参考拉回是弱约束

稳态偏移 Δw = (η/γ)·a_i·a_j = 10·a_i·a_j。a_i=a_j=0.3 时已达饱和边界。

### (c) 权重更新的二阶特征根 λ₁ ≈ 0.99

特征方程：λ² − (1−γ−K_d)·λ − K_d = 0 → λ² − 0.69λ − 0.3 = 0
λ₁ ≈ 0.99，收敛时间常数 ~100 轮交互。

### (d) 扩散收敛取决于 W 的谱半径

入度权重列和无归一化约束。赫布使权重增长 → 谱半径增长 → 发散。

**关键结论**：任何参数都无法同时保证"赫布学习有效"和"扩散无条件收敛"。

## 3/5 LLM 的角色归属

- **不是控制输入**：LLM 行为不可预测、不可建模
- **不是扰动**：LLM 的"预训练人格覆盖"是结构性模式切换，不是有界扰动

**准确物理学类比**：LLM 是一个独立动力系统（万亿参数状态空间），海波在其输入边界施加微弱偏置。这是 boundary control 问题，耦合强度由注入信号尺度决定（std 差 33 倍）。

## 5/5 指派 1 回答：赫布学习与扩散收敛是否数学兼容？

### 结论

**不兼容。反例已构造并验证。**

最小反例：3 节点全连通有向图。
初始权重 0.5 → 3 次高共现交互后 ρ(W̃) ≈ 1.99 → ρ(A)=1.099 > 1 → 扩散发散。

数据（η=0.1, γ=0.01, K_d=0.3）：

| 节点数 | 拓扑 | ρ(W̃) 稳态 | ρ(A) | 状态 |
|--------|------|-----------|------|------|
| 2 | 全连通 | 0.995 | 0.9995 | 边缘稳定 |
| 3 | 全连通 | 1.989 | 1.099 | **发散** |
| 4 | 全连通 | 2.984 | 1.198 | **发散** |
| 4 | 有向环 | 0.995 | 0.9995 | 边缘稳定 |
| 4 | 星型 | ≈ 0 | 0.9 | 稳定 |

### 谱半径分析

扩散迭代矩阵 A = (1-α)I + α·W̃。
λ(A) = 1-α + α·μ(W)。收敛要求 ρ(W) < 1。

注：正确条件是 ρ(W) < 1，不是 ρ(W) ≤ 1/(1-α)。后者是代数错误。

### 最小改动方案

**推荐：方案 D — 权重入度列和归一化**（~15 行代码）

每步权重更新后：
```
for each target node j:
    total = Σ_i w_{ij}
    if total > 1:
        for each edge i→j: w_{ij} = w_{ij} / total
```

效果：ρ(W̃) ≤ 1 永远成立。权重相对比例保持。
代价：权重绝对值失去语义。

备选方案对比：

| 方案 | 改动量 | 谱半径保证 | 敏感度保留 |
|------|--------|-----------|-----------|
| A: 扩散归一化 | 10 行 | ≤1 | ❌ 过平滑 |
| B: Oja's rule | 5 行 | ❌ 仍发散 | 🟡 部分 |
| C: 自适应 α | 10 行 | ≤1 | ❌ 过平滑 |
| **D: 权重归一化** | **15 行** | **√** | **√** |
| E: 增强 γ→0.1 | 1 行 | 🟡 改善 | 🟡 部分 |
