# BriLLM 分析 + 对 Haibo Semantics Graph 的定位

## BriLLM 是什么

上海交大提出的"类脑大语言模型"。核心理念：

1. **Static Semantic Mapping**：token 映射到"专化节点"（类比大脑皮层区域）——**这和我们的 Semantics Graph 的"词→概念节点"是同一件事**
2. **Dynamic Signal Propagation**：信号在图结构中传播（模拟脑电生理动力学）——**和我们的激活扩散是同一件事**
3. **SiFu (Signal Fully-connected flowing) Learning**：新学习范式，替换 Attention

**最基本的主张：一个语义图结构本身可以代替 Transformer 做语言建模。**

## 相关点分析

### ✅ 对我们有利的

**BriLLM 证明了"词→语义节点映射 + 信号传播"是可以站住的研究方向。** 一个正经学术团队（上海交大）投入资源做的论文，走的路线和我们一致。这说明：

- 不是"只有我们这么想"——这是一个被独立验证的共同直觉
- 我们的"围合"（词序列→概念激活→语境定位）可以被重新描述为 BriLLM 静态映射 + 动态传播的一个**极简子集**
- BriLLM 没有做语义歧义消解——他们的图是全局语言模型，我们在做的（歧义词在概念空间的定位）是他们的图能做什么的一个具体应用场景

### ❌ 对我们的挑战

**BriLLM 的规模和我们差了 7-8 个数量级：**

| 维度 | BriLLM | 我们的 Semantics Graph v0 |
|------|--------|--------------------------|
| 节点数 | 未明确，但 100-200B 参数 | 2 组 × 10-15 个概念节点 |
| 训练方式 | SiFu 学习（端到端训练） | 手写 + 共现统计 |
| 能力 | GPT-1 级生成 | 歧义消解 |
| 声称 | 完整 LLM 替代 | 前端过滤器 |

这意味着：**我们的方向在学术上被验证为可行，但需要大量数据、计算和训练才能达到 BriLLM 声称的效果。** 我们的手写 30 节点图如果不做规模扩展，就永远不能自称"类脑 LLM"。

### 关键区别

BriLLM 把语义图做成 LLM **本身**。我们把语义图做成 LLM **前端**。

| 定位 | BriLLM | Haibo Semantics Graph |
|------|--------|----------------------|
| 图的作用 | 替代 Transformer 的全部计算 | 在 LLM 之前做语义消歧和状态追踪 |
| 输出 | 直接生成文本 token | 输出消歧标签或概念激活分布 |
| 规模要求 | 100B 参数 | 30-100 节点 |
| 可解释性 | 节点级 | ✅ 完全可解释 |
| 落地难度 | 极高 | 低 |

## 对我们的 Semantics Graph 的结论

**站得住。** 不是作为 BriLLM 的竞争者——那是不可能的——而是作为：

### 一个 BriLLM 没有做的子问题

BriLLM 的 Static Semantic Mapping 假设 token 到节点的映射是**固定的、预定义的**（"皮质区"）。但语义是**上下文相关的**——"苹果"在科技句和水果句中应该映射到不同的概念区域。

**这个"上下文相关映射"问题，BriLLM 没有解决。** 他们的图是静态的——token 始终映射到同一节点。但我们的"围合"机制就是专门为这个做的：**用输入中的其他词来决定歧义词应该映射到哪个概念区域。**

### 所以 Semantics Graph 的正确定位是

> 一个**上下文依赖的语义映射器**，不是替代 LLM 的模型。
> 
> 输入：词序列
> 图：概念节点 + word→concept 归属边（一个词可属多个概念）
> 机制：输入词集激活对应概念节点 → 扩散 → 确定哪个概念区域激活最强 → 输出歧义标签
> 
> 输出用于：修改 LLM 的输入文本（替换歧义词）或作为额外上下文
> 
> 这不是 BriLLM 的缩小版——这是 BriLLM 框架下**一个未被解决的子问题**的专门解决方案。
