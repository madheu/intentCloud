## 前提确认

Control Scientist 在首次审查中做出了**结构分析**（预测：赫布学习与扩散收敛不兼容）。pilot 数据随后对其进行了**实验确认**。结构分析 + 实验确认 同时指向同一结论——这是科学上最强的信号。

三个确定性结论已被实验支持：

| 结论 | 证据 |
|------|------|
| Input embedding 注入耦合强度不足 | class separation ratio ≈ 0.93, MI ≈ 0 |
| GPT-2 结果不跨模型泛化 | GPT-2 有效 → Qwen 1.5B Instruct 无效 |
| 非参数问题 | 信噪比差距是结构性的，无 η/γ/K_d 可跨越 |

---

## 最终决策：路径 C —— 项目转向

**决策**：终止"图结构控制 LLM 生成"的核心假设路径。项目现有工程成果重新打包为可部署的技能/工具。

**原因**：

1. **核心假设 H1 被实验证伪**：动态认知图状态无法在可测量维度上改变 LLM 输出
   - 证据：MI ≈ 0，class separation ratio ≈ 0.93
   - Control Scientist：在任何注入方式下，只要 LLM 的内部状态空间远大于注入信号的维度，LLM 就可以选择忽略

2. **假设 H3 被数学证伪**：赫布学习与扩散收敛在结构上不兼容
   - Control Scientist 首次审查已证明，pilot 数据间接确认

3. **假设 H4 被实验证伪**：input embedding 注入信号不足以覆盖 LLM 先验
   - GPT-2 有效但 Qwen 无效——控制器依赖弱先验假设，跨模型不泛化

4. **假设 H2、H5、H6 尚未检验，但前提（H1/H3/H4）已不成立**

**结论**：三个核心假设（H1/H3/H4）中全部被证伪或数学证否。在当前技术路径下继续投资不符合资源约束意识。

## 未关闭的选项（如果资源允许）

Control Scientist 指出：如果希望继续"认知架构"方向，需要**更换控制接口**——放弃 input embedding 注入，转向 LoRA 微调或中间层 hidden state 注入。

**这是一个全新的技术路径**，不是当前项目的延续。需要：
- 重新评估可行性（LoRA 需要训练数据、计算资源、评估指标）
- 重新定义假设（放弃"不修改 LLM 参数"原则）
- 重新评估资源投入（训练周期 vs 当前工程积累的价值）

**PI 意见**：在当前阶段不建议立即启动。先完成路径 C 的工程成果打包，让项目有一个可交付的状态。如果后续资源允许且问题仍然吸引你，可以以新项目的形式启动"Haibo v2"。
