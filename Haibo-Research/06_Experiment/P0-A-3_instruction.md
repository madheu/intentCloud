# P0-A-3 实验指令 — 给执行者

## 背景

P0-A-2 的自动扩展有效（花 +50%，行 +20%）但被跨类重叠拉了后腿（光 -16%，苹果 -9%）。重叠大多来自语义相近的概念共用近邻词（如"开花"既属于水果_品质也属于自然_植物）。

## 目标

在自动扩展后加一层**跨类重叠过滤**，去掉那些出现在太多概念中的近邻词。

## 方法

### 方法 D：单字过滤（先做这个——根因修正）

**诊断出之前过滤无效的原因**：光卡在 17% 不是因为跨类重叠，是词向量扩展把单字"强"加入语言_评价概念，"强烈"中的"强"被子串匹配到语言域，导致自然和语言平局。

**在所有过滤方法之前，先做单字过滤：**

```
对每个概念的扩展词表 L_C:
   移除所有长度 = 1 的词（"强"、"的"、"大"、"好"等）
   
对分词函数：
   不能用子串匹配（"强烈"→"强"+"烈"）
   改用结巴分词（jieba）或至少按词表中最长匹配优先+整词匹配
```

### Step 1：单字过滤 + 结巴分词（或整词匹配）

先只做这个改动，跑测试。

### Step 2：如果正确率提升到 50%+，再叠加跨类过滤

如果单字过滤后光回到 33%+，总正确率 50%+，说明根因已解决。如果还想提升，再跑 Step 3。

### Step 3（可选）：跨类重叠过滤

复用方法 A/B/C，但基于 Step 1 的结果上做。

## 实验步骤

### Step 1：单字过滤 + 整词匹配

在自动扩展后，过滤所有单字词。并修改 tokenize 函数为整词匹配（不子串）或结巴分词。

### Step 2：测试

用 P0-A-1 全部测试句验证。

### Step 3（可选）：叠加跨类重叠过滤

如果 Step 1 后正确率 < 60%，在 Step 1 基础上跑方法 A/B/C。

```
对每个概念 C，用词向量扩展出词表 L_C
对每个词 w ∈ L_C:
    count = w 出现在多少个不同概念的扩展词表中
    if count >= THRESHOLD: 从所有概念中移除 w
    else: 保留
```

测试 THRESHOLD = 2, 3, 4（即：一个词出现在超过 2/3/4 个概念中就移除）

### 方法 B：TF-IDF 风格过滤

```
对每个概念 C，用词向量扩展出词表 L_C（保留近邻距离得分）
对每个概念 C 的每个词 w:
    tf = 1（出现在本概念中）
    df = w 出现在多少个概念中
    idf = log(N_concepts / df)  其中 N_concepts = 概念总数
    score = tf × idf
    
    如果 score < FILTER_THRESHOLD: 从本概念中移除 w
```

### 方法 C：best-friend 过滤

```
对每个概念 C 的每个词 w:
    如果 w 的最佳近邻（距离最近的前 3 个）中有超过 1 个属于另一个概念 D ≠ C:
        说明 w 是 D 的"游客"，不是 C 的"本地人" → 从 C 中移除
```

## 实验步骤

### Step 1：实现三种过滤方法

继承 P0-A-2 的自动扩展脚本，在扩展后加入过滤步骤。

### Step 2：对每种配置跑测试

| 方法 | 参数 | 
|:----|:----|
| 无过滤（P0-A-2基线） | — |
| 硬阈值 | threshold=2 |
| 硬阈值 | threshold=3 |
| 硬阈值 | threshold=4 |
| TF-IDF | filter_threshold=0.3 |
| TF-IDF | filter_threshold=0.5 |
| best-friend | top_k=3, max_foreign=1 |

### Step 3：对比输出

输出每个配置下：
- 总正确率
- 每个歧义词的正确率
- 过滤后词表还剩多少词
- 跨类重叠率
