# P0-A-6 实验指令 — 给执行者（2026-07-19 重写）

## 方向变更

之前方向：补全布尔 4 轴词表 → 验证分类准确率。
新方向：**用 Frame Semantics 取代布尔向量作为图的一层结构。**

原因：P0-A-5 的 50% 和 P0-A-6 的 34% 共同说明——手工词表的覆盖永远追不上 jieba 的分词。这不是"补词不够"，是实验方法本身依赖不可控的分词接口。

同时，ChatGPT 和今天讨论确认了一个判断：**海波不应重新发明语义分类学，应直接采用已有语言学理论。**

## 新实验设计

### 替换方案：Frame-based 消歧

不再用布尔向量（词 → 4 轴 → 点积比较），改用 Frame Semantics：

```
对每个歧义词，定义它可能激活的语义框架（Frame）。

框架 = 一组语义槽（Slot）。
每个槽有默认填充词（Default Fillers）。

给定输入句子：
1. 看句子中出现了哪些框架的默认填充词
2. 出现最多的框架 = 当前语义方向
```

### 示例

**歧义词"苹果"的两个框架：**

```
框架：科技公司
  槽：产品（手机、芯片、屏幕、系统、应用）
  槽：商业（发布、商店、价格、营收、新款）
  槽：创新（研发、性能、提升、生态）

框架：水果
  槽：生长（树、开花、采摘、季节、种植）
  槽：味道（甜、好吃、口感、含糖量）
  槽：外观（果肉、果皮、色泽、鲜艳）
```

消歧逻辑：

```
"苹果发布了新款手机"
  → 命中科技公司框架的：发布(商业)、新款(商业)、手机(产品)
  → 命中水果框架的：（无）
  → → 科技公司

"苹果的采摘季节到了"
  → 命中水果框架的：采摘(生长)、季节(生长)
  → 命中科技公司框架的：（无）
  → → 水果
```

### 和布尔向量的关键区别

| 维度 | 布尔 4 轴 | Frame-based |
|:----|:---------|:------------|
| 分类方式 | 点积比较 | 框架命中计数 |
| 词表依赖 | 每个词需要 4 bit | 每个词只需在一个框架的槽里出现一次 |
| jieba 敏感度 | 高（整词必须匹配） | 高（同左，但框架有冗余填充词） |
| 理论来源 | 自创 | Fillmore Frame Semantics |
| 扩展方式 | 加词表 | 加框架/加槽 |

### 实验步骤

**Step 1：为 6 个歧义词定义框架**

| 歧义词 | 框架 1 | 框架 2 |
|:------:|:------|:------|
| 苹果 | 科技公司 | 水果 |
| 纸 | 办公文书 | 日用包装 |
| 光 | 物理光学 | 修辞评价 |
| 花 | 植物 | 消费 |
| 行 | 评价 | 排列 | 行业 |
| 口 | 人体器官 | 空间出入口 |

**Step 2：对每个框架定义槽和默认填充词**

从所有测试句中提取每种框架下出现的词，填入对应槽。

**Step 3：改写消歧逻辑**

```
对每个句子 S:
  对歧义词的每个候选框架 F:
    对框架 F 的每个槽 S:
      对槽 S 的每个填充词 w:
        if w 在句子 S 中:
          框架 F 的得分 += 1
  
  如果最高分框架 >= 第二高分 × 1.5:
    输出最高分框架
  否则:
    输出"不确定"
```

注意：使用**子串匹配**（不是 jieba 整词匹配）。P0-A-5 已经证明子串匹配在词表不全时更鲁棒。

### Step 4：跑测试

用 P0-A-1 全部 38 句测试。
