```
你是一个中文语料生成专家。你的任务：为 20 个中文歧义词生成高质量、结构化的语境句数据集。

## 质量要求

每条句子必须同时满足以下 6 个标准：

【标准 1】句长 10-25 字（含标点）。太短的句子语境词不够，太长的句子引入噪声。
【标准 2】每个句子必须包含该歧义词 + 至少 3 个该义项特有的语境词。语境词从下方每个词的"参考语境词"列表中选取。
【标准 3】同一歧义词的不同义项使用相同的句式模板（比如科技句都主谓宾结构，水果句也都主谓宾结构）。不能科技句用"苹果公司发布了XXX"，水果句用"XXX的苹果很甜"，这种句式差异会干扰实验。
【标准 4】50 句内部要有多样性。不能"苹果发布了新手机""苹果发布了新芯片""苹果发布了新系统"——这是同一句换词。句式要变化：部分句以"苹果"开头、部分在中间、部分带"的"、部分做宾语。
【标准 5】避免评价性/情绪性句子（"苹果真了不起""苹果太好吃了"），这些偏重表达态度，不提供语义区分信息。
【标准 6】使用陈述句，不用疑问句、感叹句、反问句。

## 输出格式

严格按以下 JSON 结构输出，不加任何额外文字：

{
  "苹果": {
    "科技公司": [
      "苹果发布了搭载新芯片的手机。",

    ],

      "新鲜苹果的营养价值很丰富。",
      ...共50句
    ]
  },
  ...其他词相同格式
}

## 写作示例

好例子（优）：
- "苹果发布了搭载新芯片的手机。" → 歧义词+3个语境词（发布、芯片、手机），句式标准
- "果农正在修剪苹果树的枝条。" → 歧义词+2个语境词（果农、修剪、枝条），句式标准
- "太阳的光线经过折射分成了七色。" → 光=物理义，出现太阳、光线、折射

坏例子（劣）：
- "苹果手机很好用。" → 好：歧义词出现。坏：只有1个语境词（手机），不足3个。且"好用"是评价，不在语境词列表
- "花开了。" → 歧义词出现。坏：0个语境词，无任何消歧信息
- "他很行。" → 歧义词出现。坏：太长。且2字句不足10字。且"行"为评价义，但无任何评价义语境词

## 完成前的自检清单

提交前，对每个词每个义项的50句逐一检查：

□ 每句是否都包含了歧义词？
□ 每句是否都至少包含3个参考语境词？（不是"挺好""不错""用于、用来、以此"这类的通用词，是参考列表里的）
□ 50句之间是否有句式多样性？（主谓宾、宾谓主、短句、长句交错）
□ 义项之间的句式是否一致？（科技义和水果义都用主谓宾，而不是一个用"是"字句一个用"把"字句）
□ 是否全是陈述句？

## 特别说明

- 如果一个歧义词的某个义项很难生成50句（比如"华为"的个人义），尽力而为即可。如果某个义项只能生成20句，在对应数组里只放20句，不要重复凑数
- "行"有三个义项（评价、排列、行业）。前两个各50句，第三个（行业义）至少30句
- "苹果"的科技公司义不同于"苹果"的水果义，需要彻底区分语境词。不能混用
- 不要省略任何歧义词。20个词全部生成
- 整个输出应该是一个完整的 JSON 对象，可直接被程序加载
```
