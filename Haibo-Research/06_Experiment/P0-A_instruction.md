# P0-A 系列实验指令 — 给执行者

## 背景

Semantics Graph v1 做语义消歧的原理：
- 每个歧义词指向 2-4 个候选大类
- 句子中其他词激活各自所属的大类
- 通过分层比对确定歧义词的方向

**v1 的手写版在"苹果"上跑通 9/11（82%），但在新歧义词（纸、光、花、行）上只有 0-33%。原因是语境词没编入词→概念表。不是算法问题，是覆盖率问题。**

## 目标

利用已有的腾讯词向量（200d），自动化构建词→概念归属表，验证：
1. 能否用词向量的近邻关系自动扩展概念词表？
2. 自动扩展后的 Semantics Graph 在新歧义词上的表现？

## 实验步骤

### Step 1：定义种子词

对每个歧义词的每个候选大类，定义 5-10 个种子词：

| 歧义词 | 候选大类 | 种子词（5-10个） |
|:------:|:--------:|:----------------:|
| 纸 | 办公 | 打印, 文件, 文档, 纸张, 印刷 |
| 纸 | 生活 | 纸巾, 包装, 纸箱, 纸杯, 日常 |
| 光 | 物理 | 光线, 折射, 反射, 波长, 可见光 |
| 光 | 修辞 | 光荣, 面子, 荣誉, 光了, 光秃 |
| 花 | 植物 | 花朵, 花瓣, 花园, 盆栽, 开花 |
| 花 | 消费 | 花钱, 消费, 花费, 开销, 支出 |
| 行 | 评价 | 可以, 不行, 可行, 没问题 |
| 行 | 行列 | 队伍, 排列, 序列, 一行 |
| 行 | 行业 | 银行, 行业, 职业 |

### Step 2：用词向量扩展词表

对每个大类的种子词集合，用腾讯词向量找每个种子词的 top-20 近邻，合并去重。得到每个大类的扩展词表（预计 50-100 词）。

### Step 3：判断重叠

检查扩展后的词表是否有跨类重叠。
- 如果"办公"类和"生活"类的扩展词表重叠率 < 10%：直接使用
- 如果重叠 > 30%：需要调低近邻数或加过滤（TF-IDF 或 PMI 区分度）

### Step 4：构建 Semantics Graph

把扩展后的词表填入分层结构，推理逻辑复用 P0.10 的代码。

### Step 5：测试

用 P0-A-1 测试用例（`p0_a1_multi_ambiguous.py` 中的全部测试句）跑一遍。

## 验证通过标准

- 自动扩展后，"纸"、"光"、"花"、"行" 的正确率较手写版有提升
- 至少两个歧义词达到 60%+ 正确率
- 如果达不到：分析原因是种子词太少、近邻太噪声、还是跨类重叠太高
