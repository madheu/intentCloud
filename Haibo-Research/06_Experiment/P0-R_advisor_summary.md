# P0-R 结论摘要（给顾问）

## 做了什么
- 新建60句盲测集（20词，LLM生成，人工标金标）
- 修复P0-A的目标污染漏洞（只消歧指定目标词，不看其他歧义词）
- 38句旧集降级为开发/诊断集
- 实现5层基线（MFS→HowNet第一义项→复合词优先→词性过滤→义原重叠），层间级联

## 关键数字
| Layer | 盲测集(60) |
|:-----|:----------:|
| MFS 基线 | 55.0% |
| HowNet 第一义项 | 46.7% |
| 复合词优先 | 46.7% |
| 词性过滤 | 46.7% |
| 义原重叠 | 46.7% |
| **级联组合** | **58.3%** |

## 结论
1. MFS仍是单层最强（55%），说明语料义项分布有强偏差
2. 级联比MFS高3.3pp——语义层有增量，但信号弱
3. P0-A之前的50%低于MFS基线，14轮实验实质是在噪声中找信号
4. 当前最佳58.3%是"修复评测+LLM盲测+知识级联"的组合效应

## 当前卡点
- 语义层单跑不如MFS（静态知识无法替代语境信号）
- 58.3% vs 55%的增量太小——3.3pp意味着在60句中多对了2句
- 需要更强语义信号源：BriLLM Token底座活动向量、或更好的义原/词性匹配
