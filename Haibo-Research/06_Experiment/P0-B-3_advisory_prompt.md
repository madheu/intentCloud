# 研究顾问答复

## 核心结论

现有数据不能支持“词级语义只能做到 50%”，也不足以证明主要瓶颈是 jieba。更可能的根因是：**金标/义项体系不一致、38 句反复参与开发、把 WSD 做成话题分类、未固定目标跨度**。逐词永远预测多数标签即可得 **20/38=52.6%**，已高于已报最佳 50%，所以当前方法尚未超过 MFS 基线。

## 问题 1：错过了什么方法？

### (a) 重大遗漏

1. **评估协议。**同一批 38 句用于补词、调阈值、修噪和最终评分，没有盲测集；应加入随机、逐词 MFS、HowNet 第一义项、宏平均和置信区间。
2. **稳定的 sense inventory。**“一行代码”和“往前走三行”基本同为行列义，却标为科技/生活；“纸”按话题而非词义标注；“不确定”又充当金标。“口”的两个候选都叫生活，且评分字典会覆盖同名候选，因此口 75% 不是消歧能力。当前任务混合了 WSD、话题分类和语素分类。
3. **局部有序证据。**“花钱、花光、光说、争光、行不通、银行、伤口”等复合词、左右搭配和词性几乎直接给出答案，现有无序词袋/四轴累加丢掉了它们。
4. **直接的知识型 WSD。**P0-B-1 把 HowNet 义原压成四维并混合语境词的全部义项，信息损失过大。应比较目标候选义项与上下文候选义项的义原、关系和词性，可用 Lesk 重叠或图随机游走。
5. **上下文预训练模型。**领域强方法是上下文编码器结合释义/知识图谱，如 Huang 等的 *GlossBERT*（2019）和 Bevilacqua、Navigli 的 *EWISER*（2020）；虽超出当前资源，但属于明显漏项。

### (b) 50% 是否是词级极限？

不是。PC1 夹角约 90 度只说明“分别拟合的第一主成分不适合判别”，不能证明语义不可分；无关话题比同词两义距离更大也很正常。当前 50% 是任务定义、表示和评分协议的共同产物。认知研究也把消歧视为局部语境驱动的词义选择，参见 Swinney, *Lexical Access during Sentence Comprehension*（1979）。

### (c) 公认方法与预期

标准 WSD 基准上，主流强方法是**上下文预训练编码器 + 义项释义/知识图谱**，但没有可直接套到这套自定义中文标签的公认准确率。修正金标后，现代中文上下文模型在这些模板化短句上达到 80% 以上并不意外，但这是工程估计，不是实测。按现有资源，知识型方案的合理目标约为 68%–79%。

## 问题 2：瓶颈判断合理吗？

### (a) 判断是否合理？

局部合理，整体误诊。jieba 暴露了覆盖损失，但 P0-A-5 使用 jieba 仍达 50%，说明它不是唯一上限。根因是“分词结果必须精确命中词表”的架构；jieba 是触发器，精确查表才是脆弱点。另有目标污染：P0-A-1 会把句中所有歧义字加入推理。例如消歧“钱都花光了”的“光”时，“花”也会贡献先验。

### (b) 是否是已知问题？

中文词边界歧义是已知问题，参见 Xue, *Chinese Word Segmentation as Character Tagging*（2003）。但把“花钱”切成一个词不是 jieba 出错；若目标是其中的“花”语素，你们做的是字符/语素级消歧，必须先固定字符跨度。常见处理是字符模型、字词联合模型或词典 lattice；Zhang、Yang 的 *Chinese NER Using Lattice LSTM*（2018）虽用于 NER，但字词并行原则适用。

### (c) 折中方案

采用**目标锚定 + 词图 lattice**：先锁定目标字符位置；同时保留 jieba 词和 HowNet 合法的 2–6 字词；覆盖目标的“花钱、银行”等复合词作为强证据，周围词作为普通语境；非目标单字只有在 jieba 将其切为独立词或进入白名单时才接受。因此保留“花钱”，但不会从“强烈”抽出“强”。再加入距离、左右顺序和词性，并排除目标自身的静态向量。

## 问题 3：从零设计

### (a) 最小可行方案

1. 用 HowNet sense ID 重建六词义项表；“不确定”只作为系统弃权，不作为词义；给每个目标记录起止位置。
2. 构建 jieba + HowNet 词典 lattice，先检查覆盖目标的最长合法复合词。
3. 复合词能唯一映射到候选义项时直接判定，否则用词性过滤。
4. 对剩余候选计算：3×复合词证据 + 1.5×词性证据 + 距离加权的（义原相似度 + 0.5×腾讯向量相似度）。义项原型由中文义原名及 HowNet 关系词构成；权重在盲评前冻结，不用金标调参。
5. 分差不足才弃权；同时报告准确率、宏平均、覆盖率和 MFS。
6. 冻结后一次盲评。至少需 **26/38=68.4%**，其 95% Wilson 下界才超过 50%；25/38 的下界仍约 49.9%。

无监督聚类需要额外大语料；中文预训练模型超出资源。因此知识型级联是成本和可信度最平衡的路线。

### (b) 预期准确率

对当前不一致金标，保守估计 **23–27/38（61%–71%）**；修正为真正 HowNet 义项后，预期 **26–30/38（68%–79%）**。这是预测，不是实验结果。仅凭已参与开发的 38 句无法证明稳定性，仍需未参与设计的盲测句。

### (c) 成本与风险

**CRF 不推荐**：无序列标注数据可训练。**依存句法第二阶段再考虑**：短句上预计不如词性/搭配划算，且当前无解析器。**GNN 不推荐**：没有可靠图边、训练目标和足够数据。首版只用目标跨度、lattice、词性、HowNet 义原和腾讯向量，均可 CPU 运行且失败可解释。

## 下一步判定

暂停继续扩词表。先修订义项与金标、加入 MFS、修复目标污染，再实现目标锚定的复合词级联；否则下一轮即使超过 50%，也无法区分真实提升与继续适配这 38 句。
