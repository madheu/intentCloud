# P0-R1.1 实验指令 — 给执行者

## 背景
P0-R1 盲测 61.7% ✅。但 L5（义原重叠）0/60 触发——阈值 1.2 太高。

## 修改

### 修改 1：L5 阈值从 1.2 降为 1.05

`p0_r1_predict.py` 中 L5 判定行：

```python
# 原版
if second_score == 0 or best_score >= second_score * 1.2:

# 改为
if second_score == 0 or best_score >= second_score * 1.05:
```

### 修改 2：L5 输出详细诊断

在每条预测的 `debug` 字段中加入 L5 的完整评分（所有候选义项的得分），方便分析哪些句子上信号存在但没达到阈值。

```python
"L5_detail": {"候选A得分": 0.12, "候选B得分": 0.03}
```

### 修改 3（可选）：L3 试试宽匹配

当前 L3 只在复合词唯一匹配 HowNet 义项时才触发。可改为：复合词在 HowNet 中有多个义项时，选第一个义项并计算模糊匹配度。

## 运行

1. 应用修改到 `p0_r1_predict.py`
2. **不重跑输入文件**（dev_input.json / blind_input.json 不变）
3. 运行 `python p0_r1_predict.py`
4. 运行 `python p0_r1_score.py`
5. 对比 P0-R1 的 L5 触发数（0 → ?）

## 输出

- 修改后的脚本
- 新预测输出
- 对比表（L5 改动后 vs 改动前，看 L5 贡献了多少句）
