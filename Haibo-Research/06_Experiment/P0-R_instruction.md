1. 评测协议中38句兼任开发和测试，不能证明泛化

## 实验目标
按以下5层基线逐层实现，从简到难。每层只比较自己的成绩，不需要跨层融合。

### Layer 1：MFS 基线（1小时内完成）

**方法**：对每个歧义词，统计金标中多数义项出现频率。预测 = 选择多数义项。平局时随机选择。

**统计**：每词多数义项预测的正确数

**注意**：开发集和盲测集的 MFS 需要分别计算

### Layer 2：HowNet 第一义项基线（2小时）

**方法**：使用 OpenHowNet 获取每个歧义词在 HowNet 中的第一个义项，作为预测。

**预期**：没有语境信息，接近于随机。这是用来证明"不看不猜到做不出消歧"的底线

### Layer 3：复合词优先（核心新功能，3小时）

**方法**：
```
给定一个句子 S 和目标词 T（字符跨度）：
1. 用 jieba 分词 S，找出所有覆盖 T 的 jieba 词及位置
2. 用 HowNet 检查覆盖词：是否在 HowNet 中有且只有一个义项匹配 T 的候选义项？
3. 如果是：直接输出该义项。如果需要决策：递交给 Layer 4
```

**关键**：目标锚定必须正确实现。不是"整个句子里找所有歧义词"，是"只看指定的那个目标词"。这修复了 P0-A 的污染漏洞。

### Layer 4：词性过滤（2小时）

**方法**：利用 jieba 的 pos（词性标注），检查目标词在句中的词性。
- 如果目标词标注为 n（名词）→ 过滤非名词的候选义项
- 如果标注为 v（动词）→ 过滤非动词的候选
- 如果标注为 m（量词）→ 仅保留量词义项

### Layer 5：HowNet 义原图重叠评分（3小时）

**方法**：对 Layer 4 仍无法决定的，用 HowNet 义原重叠评分。
```
score(候选义项) = |义原(候选) ∩ 义原(上下文词-仅非歧义词)| / |义原(候选)|
```

**上下文词的义原**：取句中非歧义的安全词（金标中标为非歧义的），提取其 HowNet 义原集。

## 约束

- **不用腾讯200d向量**：v1 只用符号推理
- **不用结巴替子串匹配**：用 jieba pos 作为词性来源，但目标词的匹配不受分词限制
- **权重在盲测前冻结**：开发集上选定层之间的权重，在盲测集运行前锁定
- **不调 LLM 参数、不查金标**：盲测集在运行结束前，任何代码不得读取金标文件

## 通过标准
- 组合所有层的盲测正确率 ≥ **53.3%**（至少比随机和MFS都好）
