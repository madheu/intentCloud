# P0-A-4 实验指令 — 给执行者（v2，按词性过滤）

## 背景

P0-A-3 的跨类重叠过滤对"光"无效。诊断发现根因是**词向量扩展把单字形容词"强"加入了语言_评价词表**，子串匹配从"强烈"中提取出"强"导致自然=语言平局。

但**不能一刀切过滤所有单字词**——"花"、"光"、"红"是有效的语义承载单字，"钱"、"树"、"门"也是。过滤单字会杀错核心词。

## 修复方案：按词性分层过滤

**思路**：名词/动词是语义承载词，保留。形容词/副词/虚词是语法功能词，过滤。

### 修复 1：POS 标记过滤

在自动扩展后，用结巴的 POS 标记（词性标注）过滤扩展词表：

```python
import jieba.posseg as pseg

# 保留的词性（语义承载词）：
#   n, nr, ns, nt, nz — 名词
#   v, vd, vn — 动词  
#   a, ad, an — 形容词（但注意"强"、"大"这类单字形容词）
#
# 过滤的词性（语法功能词）：
#   c — 连词（"和"、"与"）
#   p — 介词（"在"、"从"）
#   u — 助词（"的"、"了"）
#   d — 副词（"很"、"都"）
#   r — 代词（"他"、"这"）
#   q — 量词（"个"、"条"）
#   m — 数词（"一"、"百"）
#   e — 叹词（"啊"、"哦"）
#   y — 语气词（"吗"、"呢"）
#   w — 标点

POS_KEEP = {"n", "nr", "ns", "nt", "nz", "v", "vd", "vn",
            "a", "ad", "an"}  # 保留名词、动词、形容词

POS_DENY = {"c", "p", "u", "d", "r", "q", "m", "e", "y", "w"}
```

### 修复 2：分词整词匹配

用结巴分词替代子串匹配：
```python
import jieba
words_in_sentence = set(jieba.lcut(sentence))
found = {w for w in all_words if w in words_in_sentence}  # 整词匹配
```

### 修复 3：歧义词也做整词匹配

关键改动：**歧义词本身也做整词匹配**（不子串）。但"花"在"花园"中是 jieba 复合词的一部分 → "花园" 不会被拆成 "花"+"园"。

**补救**：对每个歧义词，检查 jieba 分词结果中是否有包含该歧义词的词。例如：
- "花园" → 包含"花" → 找到"花"作为歧义词，但标记为"复合词的一部分"
- 复合词部分的歧义词——是否应该激活？看复合词的语义方向：

```
"花园"：花的自然语义明显 → 激活自然_植物
"花钱"：花的消费语义明显 → 激活生活_消费
"开花"：花的自然语义明显 → 激活自然_植物
```

如果实现复杂，可以退回到**子串匹配只对歧义词本身**（修复 2 的整词匹配只对普通词）。

## 实验步骤

### Step 1：POS 过滤 + 结巴分词（整词匹配）

1. 复用 P0-A-2 的自动扩展代码 `p0_a2_auto_expand.py`
2. 扩展后，用结巴 POS 标记每个词，只保留 POS_KEEP 中的词性（修复1）
3. 分词改结巴整词匹配（修复2），歧义词做特殊处理（修复3）
4. 跑 P0-A-1 全部测试句

### Step 2：如花的正确率仍 < 50%，退回到"普通词整词匹配 + 歧义词子串匹配"

```python
# 普通词：整词匹配
for w in all_words:
    if w not in AMBIGUOUS and w in words_in_sentence:
        found.add(w)

# 歧义词：子串匹配（保留"花"从"花园"中被提取的能力）
for aw in AMBIGUOUS:
    if aw in sentence:
        found.add(aw)
```
