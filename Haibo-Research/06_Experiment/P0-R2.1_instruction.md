## 修改

### 修改 1：阈值 1.2 → 1.05

`p0_r2_predict.py` 中 L5-embedding 判定行：

```python

# 改为
if second_score == 0 or best_score >= second_score * 1.05:
```

### 修改 3：语境词覆盖扩大

当前只匹配完全在腾讯词表中的词。很多字（"花"、"光"等）在腾讯词表中有独立向量，但当前子串匹配可能漏掉。

改进：
```python
# 当前：看在腾讯表中的独立词
context_words = [w for w in kv.key_to_index if w != target_word and w in sentence]

# 改进：加用 jieba 分词后的词（取交集），确保多字语境词也被覆盖
jieba_words = set(jieba.lcut(sentence))
context_words = list(set(
    [w for w in context_words] +
    [w for w in jieba_words if w in kv and w != target_word]
))
```

### 修改 4：多候选得分详情输出

每条预测的 debug 加入完整的 L5 评分明细：
```python
"L5_detail": {"候选A": 0.45, "候选B": 0.32}
```

方便分析哪些句子上区分度好、哪些不好。

## 通过标准
- L5 触发数 ≥ 3/60（至少有两句以上有区分信号）
- 级联盲测 ≥ P0-R2 的 63.3%
- 如果降阈值后 L5 触发 > 10 句但正确率暴跌 → 说明信号本质上弱，恢复高阈值并停止调参
