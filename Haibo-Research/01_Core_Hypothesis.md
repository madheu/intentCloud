# 核心假设文档（Haibo 2.0）

> 更新：2026-07-18 | Haibo 1.0 五个假设中 H3 已被证伪，H1/H2 因注入失效而不适用。
> 以下为新方向（Semantic Emergence）假设。

---

## H2.0-1：语义存在于词共现信号中

**相信**：同一语境下的词语在共现空间中自然接近。不需要图结构，不需要深度学习，仅用统计特征即可区分"苹果科技"和"苹果水果"两个语境。

**可证伪条件**：
```
50 句标记语料（25 科技 + 25 水果）
→ TF-IDF（char ngram 1-2）→ PCA 2D
→ 类间余弦距离 / 类内余弦距离均值

如果该比值 < 1.2：
→ "语境"不是词的共现所能捕捉的
→ Token Graph 缺乏基础数据支撑
→ 假设不成立
```

**实验文件**：`06_Experiment/p0_bow_apple.py`

**状态**：待运行。

---

## H2.0-2：Token Graph 可以增强词袋区分度

**相信**：在词袋已有基本区分能力的前提下，在 Token Graph 上做激活扩散（类似海波 1.0 扩散机制但作用于 Token 而非语义节点）可以进一步拉大类间距离。

**可证伪条件**（前提：H2.0-1 通过）：
```
同一 50 句语料
→ 构建 Token 共现图（节点=词，边=共现权重）
→ 输入句子激活对应 Token 节点 → 扩散
→ 对收敛后的激活向量做 PCA 2D
→ 类间/类内距离比

如果比值 ≤ 词袋 baseline 的比值：
→ Token Graph 没有额外价值
→ 假设不成立
```

**状态**：待 H2.0-1 通过后设计。

---

## H2.0-3：语义簇可以从多维度约束中涌现

**相信**：当多个 token 从不同方向同时约束同一区域时，"概念"涌现。即"苹果"的含义由相邻节点（产品维度：手机/发布会/Mac；水果维度：树/甜/水果摊）在激活空间中的相对位置共同决定。

**可证伪条件**（前提：H2.0-2 通过）：
```
构造两组强约束输入：
  组 A：{手机, 发布会, Mac} + 苹果
  组 B：{树, 甜, 水果摊} + 苹果
→ 观察苹果节点的激活向量偏移方向

如果组 A 和组 B 下苹果节点激活向量的夹角 < 30°：
→ 多维度约束没有产生不同方向的语义偏移
→ 语义涌现假设不成立
```

**状态**：待 H2.0-2 通过后设计。

---

## H2.0-4：语境 = 多个语义簇的稳态

**相信**：当一个输入句中同时激活 "手机"、"发布会"、"Mac" 三个不同 Token 节点时，它们会在 Token Graph 上形成一个稳定的激活模式——这个模式就是"语境"（Context）。

**可证伪条件**（前提：H2.0-3 通过）：
```
输入："苹果刚刚发布了新款Mac和手机"
→ 取扩散收敛后的全图激活向量
→ 与单 Token 输入（仅"苹果"）的激活向量对比

如果距离 < 0.2（cosine）：
→ 多 Token 输入没有形成新语境
→ 语境不是激活模式的稳态
→ 假设不成立
```

**状态**：待 H2.0-3 通过后设计。

```
H2.0-1（语义在词共现中）
    ↓ 通过
H2.0-2（Token Graph 可以增强区分度）
    ↓ 通过
H2.0-3（语义簇从多维度约束涌现）
    ↓ 通过

```
