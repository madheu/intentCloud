# 核心假设文档（Haibo 2.0 → H-SG）

> 最后更新：2026-07-21
> 旧假设链（H2.0-1~4）已被替换。新假设链反映 BriLLM 复核后的研究边界：Haibo 不再构建 Token Graph，而是研究 Token 活动到 Semantic Node 的跃迁。

---

## 前提：Haibo 的研究边界

BriLLM（上海交大）已覆盖：
- Token 节点化
- Token 节点间动态信号传播
- 基于信号能量的 next-token prediction

Haibo 不应重复以上。Haibo 的新核心科学问题是：

> **能否从上下文相关的 Token 活动路径中，无监督形成稳定、可复用、持久的 Semantic Node 和 Semantic Relation？**

---

## H-SG-1：语义分区

**相信：** 不同语义上下文的 Token 活动模式可以无监督形成稳定分区。

**可证伪条件：** 分区与随机打散的聚类差异不显著。

**所需实验：** 给定同一 Token（如"苹果"）在不同上下文中的 BriLLM/Token 底座活动向量，做聚类后与随机基线比较。显著优于随机 → 假设通过。

---

## H-SG-2：节点固化

**相信：** 稳定分区可以固化为可复用的 Semantic Node，而不是一次性聚类标签。

**可证伪条件（H-SG-1 通过后）：** 同一义项（如苹果=公司）跨句、跨轮不能稳定激活同一 Semantic Node。

**所需实验：** 建立 Semantic Node 池，新输入重用时优先匹配已有节点。如果新输入总是创建新节点而不是复用已有节点 → 假设不成立。

---

## H-SG-3：关系形成

**相信：** Semantic Node 之间可以从共同激活、事件结构和时序中形成可解释关系。

**可证伪条件（H-SG-2 通过后）：** 关系预测不比随机更好。

**所需实验：** 从自然文本中提取共激活的 Semantic Node 对，测试是否出现的节点对关系有统计学意义。

---

## H-SG-4：持久状态

**相信：** 节点和关系可以跨句、跨轮更新，组成 Persistent Semantic Graph。

**可证伪条件（H-SG-3 通过后）：** 增量更新后的图不比固定图更一致。

**所需实验：** 用多轮对话数据测试图的增量更新效果。如果更新后的图在一致性指标上不比未更新的基线好 → 假设不成立。

---

## H-SG-5：下游价值

**相信：** Persistent Semantic Graph 能够改善上下文一致性、目标遵循、结构规划或语言生成。

**可证伪条件（H-SG-4 通过后）：** 图中注入不比基线有显著改善（需 ≥10pp 超 MFS）。

**所需实验：** 在盲测集上比较"有 Semantic Graph"和"无 Semantic Graph"的生成质量。如果差异 < 10pp → 图没有工程价值。

---

## 假设依赖链

```
H-SG-1（语义分区）
    ↓ 通过
H-SG-2（节点固化）
    ↓ 通过
H-SG-3（关系形成）
    ↓ 通过
H-SG-4（持久状态）
    ↓ 通过
H-SG-5（下游价值）
```

**任何一层断裂，后续假设不再有意义。** 这是设计成链的原因——在早期尽快发现不可行性。

## 与 Haibo 1.0 和 H2.0 的关系

| 旧假设 | 命运 | 与新假设的关系 |
|--------|:----:|---------------|
| Haibo 1.0 H1-H5（注入控制 LLM） | **已证伪** | injection 路线已死 |
| H2.0-1（语义在词共现中） | **被替换** | P0 数据显示词级信号存在但不够精确。部分验证，但方向已修正 |
| H2.0-2（Token Graph 增强词袋） | **被替换** | BriLLM 已覆盖 Token 节点传播，不再是 Haibo 的创新点 |
| H2.0-3（语义簇涌现） | **吸收进 H-SG-1** | 类似问题，更精确的表述 |
| H2.0-4（语境=稳态） | **吸收进 H-SG-3/4** | 类似问题，拆分为关系形成和持久状态 |
